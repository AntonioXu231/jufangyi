# PL 自动快照触发与项目完整实施计划

日期：2026-09-18  
工程：`pd_feature_bd_2020_2_dds_onboard_iir_ddr1g_20260916`  
器件：`xc7z020clg400-2`；Vivado：2020.2；当前验证输入：4 通道 DDS，26 MSPS。

## 1. 本次变更的目的

既有设计能够把原始采样数据写入 PS DDR 环形缓冲，并可由 PS 通过
`FREEZE_CTRL` 手工冻结。`auto_snap_en` 已能在冻结结束后把一段数据自动
复制到四槽快照区，但它**不会自行产生冻结触发**。因此，真实局放事件到来时
仍依赖 PS 软件反应，不适合作为最终产品的实时冻结机制。

本次实现补齐以下闭环：

```text
特征核心成功保留事件
  -> event_accept[3:0]
  -> pd_snapshot_trigger
  -> freeze_trig
  -> 周期边界冻结
  -> 四槽快照复制
  -> snapshot_ready / IRQ
  -> PS 读取描述符、读取 DDR、释放槽、freeze_resume
```

这里的“成功保留事件”指事件已被写入每通道事件 FIFO，不依赖 DMA 的
`TREADY`。因此 PS/DMA 暂时反压不会改变冻结触发的时间点。

## 3. 新增寄存器约定

DDR AXI-Lite 页仍为 `0x2000`，下表中的偏移为页内偏移。

| 偏移 | 名称 | 位定义 |
|---:|---|---|
| `0x5C` | `SNAP_TRIG_CTRL` | `[0] event_trig_en`；`[4:1] event_ch_mask`；写 `[8]=1` 清除槽满拒绝计数；读 `[16] armed`、`[17] slot_full_drop`。 |
| `0xA0` | `SNAP_TRIG_DROPS` | 只读；自动触发因四个快照槽均不可用而被拒绝的累计数。 |

推荐初始配置：

```text
SLOT_CTRL.auto_snap_en = 1
SNAP_TRIG_CTRL.event_trig_en = 1
SNAP_TRIG_CTRL.event_ch_mask = 0b1111
```

软件触发 `FREEZE_CTRL[0]` 仍保留且优先。`FREEZE_CTRL[1]` 的
`freeze_resume` 是自动触发器重新武装的必要条件；PS 在确认快照状态后必须
执行该操作。

## 4. 必须执行的 BD 更新步骤

本次只修改 Verilog 文件；BD 本身不能通过文本编辑安全更新。打开本工程后，在
Vivado Tcl Console 执行：

```tcl

```

脚本预期打印：


## 7. 完整实施顺序

1. **完成本次自动快照触发。** 执行 Tcl 更新 BD，运行模块级 testbench。
2. **冻结 PL 控制契约。** 明确 `acq_en`、自动触发、软件冻结、槽锁定、槽释放、恢复的 PS 时序；写成寄存器使用说明。
3. **完成滤波配置闭环。** 确定目标带通/陷波频段和采样率，离线计算 IIR 系数，在 DDS 测试下验证幅频与稳定性；未确认系数前保持旁路为默认安全状态。
4. **进行完整 RTL 顶层快照仿真。** 覆盖事件、自动冻结、周期结束、拷贝完成、IRQ、读取/释放槽、重新采集；检查数据长度、地址不重叠与槽状态。
5. **实现真实 ADC 前端。** 建立 AD9226 接口模块、采样时钟/复位、输入延迟与 CDC；使用板级约束而不是 DDS 假设。
6. **实现 PS 数据通路。** IRQ 驱动的 slot manager、DDR cache 管理、快照解析、PS FFT、滤波系数服务和错误恢复。
7. **实现上位机最小闭环。** 配置设备、拉取单次快照、显示通道波形/事件和状态；之后加入 PRPD、频谱、长期存档。
8. **时序与上板收敛。** 在最终 RTL 固定后处理现有时钟重定义警告和负裕量；通过后再生成 bitstream、XSA 和 Vitis 平台。

## 8. 发布门禁与风险

- 当前实现历史报告存在约 `WNS=-0.278 ns`、`TNS=-0.426 ns` 的实现时序违例；在 WNS/TNS 均非负前，不得作为可部署 bitstream。
- 自动触发必须在 PS 的 `freeze_resume` 后重新武装；PS 未恢复时这是有意的单次捕获保护，不是 RTL 漏触发。
- 四槽均满时模块拒绝自动冻结，以免环形写入被无可用目标的冻结操作阻塞；拒绝次数可从 `0xA0` 读取。
- 当前 26 MSPS DDS 的 CDC/吞吐结果不能直接证明 65 MSPS 真 ADC 的时序、电气完整性和 DDR 带宽。
- 任何修改 BD 后必须先执行 `Validate Design`，再生成 target/wrapper；不要手工编辑 `.gen` 目录文件。
