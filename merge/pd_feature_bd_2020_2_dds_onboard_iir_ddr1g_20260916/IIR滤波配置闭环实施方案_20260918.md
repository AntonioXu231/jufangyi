## 0. 结论摘要

1. **软件侧闭环（系数 → AXI-Lite 下发 → 生效 → 回读校验）在现有 RTL 上即可完成，不需要改任何 RTL。**
   寄存器映射、写序、影子组/生效组语义已全部从源码取证（§1.2）。
2. **硬件侧"扫频验证"当前做不到，卡在三个前置阻塞**（§2）：
   - **B1**：现有 `pd_dds_0` 不是正弦源，是三角波 + 脉冲发生器，**无 AXI 口、频率不可配**；
   - **B2**：`filt_data` 只进 `pd_feature_0`，**不写 DDR**，PS 读不到滤波后波形；ILA 是 AXIS 监视器，也抓不到；
   - **B3**：两级饱和**没有任何溢出标志位**，"验证溢出状态"无寄存器可读。
3. **系数已实算并验证可量化**（§3）：目标带 100 kHz–1 MHz、单节二阶带通，
   `f0 = 316.23 kHz`、`Q = 0.3514`；26 MHz / 16.25 MHz / 65 MHz 三组 Q1.16 系数
   **全部无钳位、极点均在单位圆内**。
4. **关于"65 MSPS 系数"的重要更正**（§3.5）：`pd_iir_biquad` 是 **5 拍/样本**，130 MHz 下
   **65 MSPS 直连必然失效**（130/65 = 2 < 5）。真正可部署的第二组系数对应的是
   **CIC 4:1 抽取后的 16.25 MSPS**，不是 65 MHz。§3 已按此口径给出 16.25 MHz 组。
5. **可在不新增 RTL 的前提下先关掉闭环的大半**：旁路逐位一致（V4 口径）与滤波数值正确性
   都可以用 **XSim + MATLAB 逐位比对**在本机完成（§5.2）。上板频响扫频留到 B1/B2 解决后。
6. **⚠️ 09-18 新增（实算）：滤波会显著影响下游特征提取**（§1.6）。三个判据域中
   **相位域几乎不受影响**（群延迟变化折算 PRPD 相位仅 **0.016°**，极性判定也稳）；
   但**码域判据全部失效**——真实 PD 脉冲幅度被压到约 **38.1%**（单样点脉冲仅 17.6%），
   等效门槛抬高 **2.6 倍**；且**振铃负峰 = 正峰 × 13.5%**，会**产生假负极性事件**。
   → **切换滤波状态时必须同步重标 5 组参数**（`cfg_scale` / `cfg_thresh` / 两档 `thr` / `cfg_deadtime`），
   禁止"旁路态标定、滤波态运行"。
7. **⚠️ 顺带更正一条已记录的理由**：项目文档中"IIR 非线性相位先于 FFT → 污染 PRPD 相位"
   **在数量级上不成立**（实算 0.016°，而 PRPD bin 是 0.016°–0.35°）。
   真正站得住的理由是**有损不可逆 + 波形失真 + 职责解耦**（详见 §1.6(1) 的说明框）。

## 1. 已核实的接口事实（取证，可直接引用）

### 1.1 信号链（来自 `.bd` 网表段，非推测）

`pd_feature_bd.bd` 的顶层 nets 段（**L4099–L4254**）确认：

```
pd_dds_0 ──adc_data/adc_dv──▶ pd_ddr_0/adc_data,adc_dv      [原始样点]
                                   │
                                   ├─▶ 环形缓冲写 DDR（存档支路，存原始样点）
                                   └─▶ o_feat_data / o_feat_dv   （扇出副本）
                                             │
                                    pd_filter_0/adc_data, adc_dv
                                             │
                                    filt_data / filt_dv   ← 只此一个去向
                                             │
                                    pd_feature_0/adc_data, adc_dv   [判决支路]
                                             │
                                    m_axis ──▶ axi_dma_0 S2MM

另：pd_feature_0/o_event_accept ──▶ pd_ddr_0/i_event_accept   （自动快照触发，已连通）
```

**关键推论（B2 的根源）**：滤波**只作用于判决支路**，DDR 里存的是 `pd_ddr_0` 扇出的**原始**样点。
因此**PS 无法通过读 DDR 得到 `filt_data`**。

### 1.2 寄存器映射（`pd_filter_chain.v` 实读，非文档转述）

来源：`pd_feature_bd_2020_2.srcs/sources_1/imports/rtl/pd_filter_chain.v`

页基址 **`0x4002_0000`**（BD addressing 段确认：`SEG_pd_filter_0_reg0 offset 0x40020000`，range 64K）。
同页参考：`pd_feature_0 = 0x4000_0000`、`pd_ddr_0 = 0x4001_0000`、`axi_dma_0 = 0x4040_0000`。

**全局寄存器**（`wa < 0x010`，由 `wa[3:2]` 解码，`pd_filter_chain.v:89`）

| 偏移 | 名称 | 位定义 | 读/写 |
|---:|---|---|---|
| `0x00` | `FCTRL` | `[0]` `fctrl_bypass`；`[1]` **APPLY（单拍脉冲）**；`[2]` **CLEAR（单拍脉冲）** | R/W（**仅 `WSTRB[0]=1` 时生效**，见 L90） |
| `0x04` | `FSTATUS` | `[15:8]` 版本 = `0x04`；`[1]` `coef_dirty`；`[0]` `apply_p\|clear_p` | 只读 |
| `0x08` | `FBYPASS_MASK` | `[NUM_CH-1:0]` 逐通道旁路 | R/W |
| `0x0C` | `FSAMPLE_HZ` | 回读参数 `SAMPLE_HZ` | 只读 |

`pd_filter_chain.v:102` 原文：
`1:read_mux={16'd0,8'h04,6'd0,coef_dirty,(apply_p|clear_p)};`
→ 版本号在 `[15:8]`；`[1]` 是 `coef_dirty`；`[0]` 是 apply/clear 脉冲。

**系数区**（`wa >= 0x010`，`pd_filter_chain.v:71-74`）

```
ca  = wa - 0x010
c_ch    = ca[10:9]   → 通道步长 0x200
c_stage = ca[7:5]    → 节步长   0x20
c_reg   = ca[4:2]    → 寄存器步长 0x04
c_valid = (c_ch < NUM_CH) && (c_stage < N_STAGE) && (c_reg <= 5)
```

`N_STAGE = N_BP + N_NT = 1 + 0 = 1`（`pd_filter_chain.v:35`）→ **`c_stage` 只能取 0**。

| 块内偏移 | `c_reg` | 含义 |
|---:|---:|---|
| `+0x00` | 0 | 该节影子使能 `sh_en`（只用 `bit0`，见 L94） |
| `+0x04` | 1 | `b0` |
| `+0x08` | 2 | `b1` |
| `+0x0C` | 3 | `b2` |
| `+0x10` | 4 | `a1` |
| `+0x14` | 5 | `a2` |

**逐通道绝对地址**（页内偏移）

| 通道 | `en` | `b0` | `b1` | `b2` | `a1` | `a2` |
|---|---:|---:|---:|---:|---:|---:|
| ch0 | `0x010` | `0x014` | `0x018` | `0x01C` | `0x020` | `0x024` |
| ch1 | `0x210` | `0x214` | `0x218` | `0x21C` | `0x220` | `0x224` |
| ch2 | `0x410` | `0x414` | `0x418` | `0x41C` | `0x420` | `0x424` |
| ch3 | `0x610` | `0x614` | `0x618` | `0x61C` | `0x620` | `0x624` |

**写数据只用低 `CW = 18` 位**（`mergecoef`，`pd_filter_chain.v:63-66`：`mergecoef = t[CW-1:0]`）。
→ 负系数按 **18 位二位补码放入 `WDATA[17:0]`**，高位任意（建议填符号扩展），`WSTRB` 用 `0xF`。

### 1.3 数值口径（`pd_iir_biquad.v` 实读）

参数：`DW=16, CW=18, FW=16, PH=5`；`PW = DW+CW = 34`，`AW = PW+3 = 37`。

- **系数格式 = Q1.16**：整数系数 = `round(归一化系数 × 2^16)`；
  恒等节定义为 `b0 = ONE_C = 2^16`（`pd_filter_chain.v:36`）。
  18 位可表示范围 `[-2, +1.99998]`。
- **差分方程（相位逐拍推演，`pd_iir_biquad.v:34-70`）**：

  ```
  y[n] = b0·x[n] + b1·x[n-1] + b2·x[n-2] − a1·y[n-1] − a2·y[n-2]
  ```

  `phase0` 取 `x[n],y1` → `prod = x[n]·b0 − y1·a1`；
  `phase1` 取 `x1,y2` → `acc = (x[n]·b0 − y1·a1) + x1·b1 − y2·a2`；
  `phase2` 取 `x2` → `acc += x2·b2`（`L68-70`）。
  **`a1/a2` 是相减项**，与 MATLAB `filter(b,a,·)` 的 `a=[1 a1 a2]` 约定一致 →
  **直接填 `a(2)`、`a(3)`，不要自行变号**（`pd_iir_biquad.v:45` 原文 `sum1 = pa_ext - pb_ext`）。
  `b1 = 0` 时 `phase1` 只贡献 `−y1·a1`，寄存器写 0 即可。
- **舍入**：`rounded = acc + (1 <<< (FW-1))`，`shifted = rounded >>> FW`（`L48-49`）→ 四舍五入。
- **两级饱和（B3 的根源）**：
  1. `pd_iir_biquad.v:50-53`：饱和到 16 位 `[−32768, +32767]`；
  2. `pd_filter_chain.v:113`：`yc = (y>2047)?2047:(y<-2048)?-2048:y[11:0]` → 再饱和到 12 位。

  **两级都是静默饱和，没有任何 sticky 溢出位输出到寄存器。**
- **延迟**：单节流水 **5 拍/样本**（文件头注释 `Five-clock, second-order IIR section` + `PH=5` + `initial $error("pd_iir_biquad requires PH=5")`，`L27-29`）。
  130 MHz 下 5 拍 = **38.46 ns**。
- **相位状态机（65 MSPS 失效的原因，`pd_iir_biquad.v:55-60`）**：

  ```
  if (!rst_n || clr)  phase <= 0;
  else if (dv)        phase <= 1;      // ← dv 优先级最高
  else if (phase==4)  phase <= 0;
  else if (phase!=0)  phase <= phase+1;
  ```

  26 MSPS @130 MHz：`dv` 每 5 拍一次 → 恰好走完 0→1→2→3→4，**零余量**。
  65 MSPS @130 MHz：`dv` 每 2 拍一次 → `phase` 在 1、2 之间被反复复位，
  **永远到不了 4 → `dout_dv` 恒 0 → 滤波输出冻结**。
- **旁路语义（`pd_filter_chain.v:113-115`）**：

  ```
  bypass     = fctrl_bypass | bypass_mask[ch]
  filt_data  = bypass ? raw : (yc + 12'h800)     // 回到偏移二进制
  filt_dv    = bypass ? adc_dv[ch] : sv[N_STAGE]
  ```

  **复位默认值**：`fctrl_bypass = 1`、`bypass_mask = 4'b1111`（`L86`）→ **逐位旁路**。
- **`ac_en` 门控（静默失效机理，`pd_filter_chain.v:111`）**：

  ```
  c_b0 = ac_en ? ac_coef[CB]   : ONE_C
  c_b1 = ac_en ? ac_coef[CB+1] : 0
  ... c_a2 = ac_en ? ac_coef[CB+4] : 0
  ```

  `ac_en = 0` → 该节恒等 → **输出 = 输入，且 `filt_dv` 正常** →
  **"系数写了但忘了使能"与"滤波生效了"在寄存器状态字上无法区分**。必须靠回读校验（§4 步骤 3）。

### 1.4 当前激励源的真实形态（`pd_dds_adc_source.v` 实读）

`pd_dds_0` 的 vlvn 是 `xilinx.com:module_ref:pd_dds_adc_source:1.0`。
端口仅 `clk, rst_n, adc_data, adc_dv, sync_in`（`L19-25`）——**没有 AXI 接口，没有任何寄存器**。

- **不是正弦源**。波形由 `tri_wave(phase)` 产生（`L35-42`）：三角波。
  相位步长固定写死：ch0/1/2/3 = `+3/+5/+7/+11`（`L110-113`），模 256 →
  **四通道周期都是 256 样点 = 26e6/256 = 101.5625 kHz**，只是初相不同。
- 幅度：`tri_wave >>> 2` → `0..127` 右移 2 位 = `0..31`（ch2 用 `>>>1` = `0..63`，`L74-81`）→
  ch0/1/3 约 **±31 码**、ch2 约 **±63 码**（围绕 2048/2056/2038/2062）。
- **PD 脉冲**：每通道每 20 ms（50 Hz）在 `cycle_sample = 65000/195000/325000/455000` 处
  叠加 4 个样点，幅度 `720/600/460/300`（`L44-59`），经 `saturate_u12` 钳位到 4095。
- **频率不可配、幅度不可配、无扫频能力。**

> 命名提示：`pd_feature_core.v:147` 里确有 `reg [15:0] sin_lut [0:1023]` 与
> `cfg_phase_inc`（`L280/L300/L495`），但那是**特征核内部的相位窗参考正弦**，
> 位于滤波器下游，**不能用作滤波器的激励源**。

### 1.6 ⚠️ 滤波对下游特征核的量化影响（09-18 新增实算）

链路已核实：`pd_filter_0/filt_data → pd_feature_0/adc_data` →
**判决支路的特征提取看到的就是滤波后数据**。因此一旦解除旁路（当前默认仍是逐位旁路），
下列影响立即生效。以下数字均实算自 §3.2① 那组量化系数（26 MHz / 100 kHz–1 MHz）。

**三个判据域（`pd_feature_core.v` 实读）**

| 域 | 参数 | 位置 | 滤波切换后 |
|---|---|---|---|
| **相位域** | `cfg_phase_win`、`cfg_phase_inc`、REG0/REG1 的相位区间 | `L45-46`、`L63-68` | ✅ **基本不受影响** |
| **码域** | `cfg_thresh`、`cfg_pos_thr[6]`、`cfg_neg_thr[6]` | `L47-49` | ❌ **必须重标** |
| **pC 域** | `cfg_reg0_q`、`cfg_reg1_q` | `L65/L68` | ⚠️ 随 `cfg_scale` 同步重标即恢复 |

量纲依据（`pd_feature_core.v:442-443` 原文）：

```
// 单位约定: 门槛 cfg_pos_thr/neg_thr 与 AD 极值均为 ADC 码(与 THRESH 同域),
//           非标定后的 pC —— 企业需求"放电 AD 最大最小值"即 AD 码。
```

标定链：`q_pc = sat16((q_code × cfg_scale) >> 8)`（`L390-392`）。

**(1) 相位域不受影响 —— 这是最重要的正面结论**
- 通带 100 kHz–1 MHz 内群延迟变化 **22.74 采样 = 0.875 µs → 折算 PRPD 相位仅 0.016°**
  （PRPD 常用 360/1024 bin，即 0.35°/0.016°）→ 可忽略。
- 极性判定 `pol_sel_r <= (abs13(wc_max) >= abs13(wc_min))`（`L329`）比较**窗口内正负峰绝对值**；
  振铃负峰仅正峰的 **13.5%** → **极性不会被翻转**。
- → **PRPD 横轴（相位分布）与类型识别的主依据保住了。**

> 📌 附带更正：此前记录的"IIR 非线性相位先于 FFT → 污染 PRPD 相位"这条理由，
> **在数量级上不成立**（0.016°）。真正的代价是**波形失真**（见 (2)），不是相位偏移。

**(2) 码域：幅度保留率 38.1% → 等效门槛被抬高 2.6 倍**

| 输入峰值 | 输出正峰 | 保留率 | 输出负峰 | >40 码宽度 | 判据 |
|---:|---:|---:|---:|---:|---|
| 60 | 22.9 | 38.1% | −3.1 | 0 样点 | **漏判** |
| 100 | **38.1** | 38.1% | −5.1 | 0 样点 | **刚好掉到门槛下** |
| 200 | 76.2 | 38.1% | −10.3 | 6 样点 | 勉强过 |
| 720 | 274.3 | 38.1% | −37.0 | 10 样点 | 过 |
| 1200 | 457.1 | 38.1% | **−61.6** | 11 样点 | ⚠️ 负峰超门槛 |
| 3000 | 1142.8 | 38.1% | **−154.0** | 12 样点 | ⚠️ 负峰是门槛的 3.9 倍 |

- **保留率恒为 38.1%**（线性滤波对固定脉冲形状给出恒定比例）→ **单一标定系数即可修正**。
- ⚠️ 但 38.1% 是 DDS 那个 **4 样点**（154 ns）脉冲的值；**单样点脉冲实测只有 17.6%**。
  **真实 PD 脉冲比 DDS 脉冲窄得多 → 实际幅度损失会更严重**，标定必须用真实脉冲形状。

**(3) ⚠️ 新发现：会产生"假负极性事件"**
负峰 = 正峰 × 13.5% → **输入 ≥ 约 780 码的 PD 脉冲，滤波后的负向振铃就 ≥ 40 码门槛**，
于是**同一颗正极性放电会在负阈值上再触发一次**。
后果：帧正/负计数各错一次、**PRPD 正负半周各凭空多出一簇**。
→ **可操作约束：`cfg_neg_thr` 不能低于 `cfg_pos_thr` 的 13.5%**，起点建议 `≥ 0.25 ×`。

**(4) 跨相位窗重复计数**
高于门槛的宽度从 4 样点（未滤波）→ 12 样点（滤波后）→ **跨窗概率 0.8% → 2.4%**。
`pd_feature_core.v:768-770` 注释明说跨窗去重**不设回差、全靠 `cfg_deadtime`**
→ **`cfg_deadtime` 需按 ≥ 1 个相位窗重设**（26 MSPS / N=1024 / 50 Hz 下约 **508 样点**）。

**(5) 切换滤波状态时必须同步重标的参数清单**

| 参数 | 动作 | 依据 |
|---|---|---|
| `cfg_scale` | **×2.62**（1/0.381）起 | `q_pc = (q_code × scale) >> 8` |
| `cfg_thresh` | 按 38.1% 折算上调 | 码域 |
| `cfg_pos_thr[6]` / `cfg_neg_thr[6]` | 同上；**`neg_thr` 不低于 `pos_thr` 的 13.5%** | 码域 |
| `cfg_deadtime` | **≥ 1 个相位窗（≈508 样点）** | 振铃展宽跨窗 |
| REG0/REG1 的相位区间 | 不需改 | 相位域不受影响 |
| REG0/REG1 的 Q 阈值 | 不需改（前提：`cfg_scale` 已重标） | pC 域 |

> **禁止"旁路态标定、滤波态运行"** —— 那是 2.6 倍的系统性幅度偏差。
> 若滤波的目的是模拟 IEC 60270 带通测量，**衰减本身不是缺陷**（真实测量仪的带通同样衰减脉冲，
> 它靠标准电荷注入标定）；**关键只在"标定与运行必须处于同一滤波状态"**。

> **对 PRPD 图谱的净结论**：横轴（相位）几乎不动；纵轴（pC）线性缩放、标定可修；
> **同形状脉冲（同一缺陷、同传播路径）的簇形状保持**；
> 但**不同缺陷类型的脉冲形状不同 → 压缩比不同 → 跨类型的幅值比较失真，且不可逆**。

> ⚠️ 上述全部数值来自**离线定点仿真 + DDS 矩形脉冲**，**不能直接当标定值用**。
> 必须按 §6 阶段 1.7 做一次"旁路态 vs 滤波态"的实测 A/B，用真实统计量定标。

## 2. 三个前置阻塞（必须先决策，否则"扫频验证"无法执行）

### B1 — 没有可扫频的正弦激励源

- **现象**：§1.4。现有源是三角波 + 脉冲，无 AXI 口。
- **影响**：无法测幅频响应。而现有三角波本身的主频 101.56 kHz **恰好落在通带内**
  （见 §3.3：|H|@100 kHz = −3.01 dB），其 3/5/7/9 次谐波 305/508/711/914 kHz **也全在通带内**。
  → **用三角波永远演示不出"通带 / 阻带"的区别**，只能演示"直流与 50 Hz 被压掉"。
- **选项**：
  - **B1-a（建议）** 新增 `pd_dds_sweep_src.v`：NCO（相位累加器 + 正弦 LUT）+ AXI-Lite 页
    （频率字 + 幅度字 + 使能）。复用 `pd_feature_core.v:147` 的 `sin_lut` 写法；
    频率字 = `round(f × 2^32 / Fs)`，26 MHz 下分辨率 6.05 mHz，够用。
    成本：1 个模块 + 1 个 AXI 页 + 1 次 BD 改动；资源约 1 个 RAMB18（1024×16）+ 少量 LUT/DSP。
  - **B1-b** 把 `pd_dds_0` 原地改成可配正弦源（保留脉冲叠加能力）。
    改动面更小，但会破坏现有"三角波 + 脉冲"回归基准，**需新增一种模式而不是替换**。
  - **B1-c** 暂不做扫频，只做仿真验响应（§5.2），上板只验端到端效果变化。**零 RTL 成本。**

### B2 — 滤波后数据读不回来

- **现象**：§1.1。`filt_data` 唯一去向是 `pd_feature_0/adc_data`；DDR 存原始样点。
- **影响**：无法把滤波前后波形拉到 PS 做频响/时域比对。
- **选项**：
  - **B2-a** 改 BD：给 `pd_ddr_0` 增加一路"分析缓冲"入口，把 `filt_data/filt_dv` 也写进
    DDR 的另一段区域（或复用四槽的某个槽）。**改动最大，但一次性解决"以后 PS 做 FFT"的需求**
    （正好呼应 `PL数据流与滤波一体化方案_V2` 的分析支路）。
  - **B2-b** 加一路 **系统 ILA 自由探针**（非 AXIS 槽）在 `pd_filter_0/adc_data` 与 `filt_data` 上。
    **最小改动**（BD 加 1 个 ILA），但采样深度受 BRAM 限制（当前 BRAM 占用 26.5/140，
    有空间），只适合看波形形状与瞬时饱和，不适合扫频统计。
  - **B2-c** 用 `pd_feature_0` 的事件包（峰值）作为"滤波后幅度"的代理读数：
    DDS 定频 → 门槛设低 → 读事件峰值包 → 得该频点幅度。
    **零 RTL 改动**，但精度受特征核判据（默认 40 码绝对门槛 + 迟滞）限制，
    需要先把门槛降到扫频幅度以下，且需确认事件包峰值字段确实是滤波后数据的峰值。
    **先用仿真/文档确认语义再用，不要直接假设。**
  - **B2-d** 只在仿真里做（同 B1-c）。

### B3 — 没有溢出 / 饱和标志

- **现象**：§1.3 两级静默饱和，无任何状态位。
- **影响**：计划要求的"验证溢出状态"**没有寄存器可读**。
- **选项**：
  - **B3-a** 在 `pd_iir_biquad` / `pd_filter_chain` 增加 sticky 饱和标志
    （`sat_hi/sat_lo` 或 `sat_cnt`，写清位清除）。
    **空闲寄存器位置已确认**：全局写译码只用到 `wa[3:2]==0`（`0x00`）与 `==2`（`0x08`），
    而且 `0x04`（`FSTATUS`）与 `0x0C`（`FSAMPLE_HZ`）都是只读
    → **`0x05`–`0x07` 与 `0x0D`–`0x0F` 六个偏移完全空闲**，可直接用于新增状态寄存器，
    不需要改动任何既有地址语义。
  - **B3-b** 不加硬件，用**数据判据**代替：滤波后波形若出现连续贴顶/贴底
    （`2047` 或 `-2048` 连片），即判定饱和。需要 B2 先解决才能看到数据。
  - **B3-c** 只在仿真里判饱和：`tb_pd_filter_chain` 里用参考模型比对，
    统计 `|y| ≥ 32767` / `≥ 2047` 的次数。**零 RTL 成本，且最容易做。**

> **建议组合**：先走 **B1-c + B2-d + B3-c**（纯仿真）把数值闭环关掉，
> 同时按 **B1-a + B2-b + B3-a** 提交 RTL/BD 改动，用于上板扫频。
> 不要为了扫频一次性大改 BD（B2-a），除非同期就打算做 PS 端 FFT。

## 3. 系数设计（已实算，供交叉核对）

### 3.1 设计口径

- **目标带**：100 kHz – 1 MHz（09-17 口径；**尚未写入接口契约 §8**，需补）。
- **结构**：1 节二阶带通（`N_BP=1, N_NT=0`）。
- **设计方法**：RBJ 双二阶带通（0 dB 峰值增益），
  `f0 = sqrt(f_low·f_high)`、`BW = f_high − f_low`、`Q = f0 / BW`。
  `w0 = 2π f0 / Fs`，`α = sin(w0)/(2Q)`：

  ```
  b0 =  α/(1+α)      b1 = 0      b2 = −α/(1+α)
  a1 = −2cos(w0)/(1+α)           a2 = (1−α)/(1+α)
  ```

- **量化**：`Q1.16`，`int = round(coef × 65536)`，范围 `[−131072, +131071]`。
- **不带陷波节**：本组系数在 50 Hz 已提供 **−66.9 dB**（下表），无需另加陷波。
  与 `REF_工程参数与硬约束.md` §B"不需要陷波节（1 节在 50 Hz 已 −66 dB，过剩约 50 dB）"一致。
- **Q = 0.3514 < 0.5 → 两个极点落在实轴**（见下），即等效"1 级 HP × 1 级 LP"，
  两侧各 −20 dB/decade。这与 REF §B"Q=0.131<0.5 → 两极点落实轴"的定性结论同源。

### 3.2 三组 Q1.16 系数（实算输出，原文照录）

3. 输出三份产物：

### 3.5 ⚠️ 关于"65 MSPS 系数"的重要更正

用户口径是"按当前 26 MSPS 与目标 65 MSPS 分别产出两组系数"。实算后发现**该口径需要更正**：

- `pd_iir_biquad` 固定 **5 拍/样本**（`PH=5`，硬校验）。
- 65 MSPS 直连 130 MHz → `130/65 = 2` 拍/样本 **< 5** →
  `dv` 每 2 拍把 `phase` 复位到 1（`pd_iir_biquad.v:57`，`dv` 优先级最高）→
  `phase` 永远到不了 4 → `dout_dv` 恒 0 → **滤波输出冻结，功能失效**。
- 要原生跑 65 MSPS 需 `clk ≥ 325 MHz` → **xc7z020-2 不可达**。

**因此可部署的第二组系数对应的是"抽取后的 IIR 输入采样率"，不是 65 MHz。**
按 REF §B 的可行路径（判决支路 CIC 4:1 抽取）：`65 / 4 = 16.25 MSPS` →
`130/16.25 = 8` 拍/样本，**余量 1.6×** → 即 §3.2 的 **② 组**。

→ **本方案按 3 组交付：26 MHz（现在可用）、16.25 MHz（加 CIC 后可用）、65 MHz（仅参考/对比）。**
→ 若最终不做 CIC 抽取而改用其它时钟方案，则 ② 组需按实际 `Fs` 重算（脚本已参数化）。

## 4. 下发时序（安全顺序 + 完整性校验）

> 依据 §1.3：`ac_en=0` 时该节恒等而 `filt_dv` 正常 → **"看起来正常"不能当"已生效"**。
> 因此顺序必须保证**任何时刻都不存在"使能已开而系数未写完"的窗口**。

```
步骤 0  进入安全态
        写 FCTRL(0x00)        = 0x0000_0001      // fctrl_bypass = 1
        写 FBYPASS_MASK(0x08) = 0x0000_000F
        回读确认 FCTRL[0]=1、FBYPASS_MASK[3:0]=0xF

步骤 1  清影子使能（防止上电残留）
        对 ch0..ch3 写 en = 0x010 / 0x210 / 0x410 / 0x610  ← 值 0x0000_0000

步骤 2  写系数（影子组 sh_coef，此时 ac_en 仍为 0，输出仍旁路）
        每通道写：+0x04=b0, +0x08=b1=0, +0x0C=b2, +0x10=a1, +0x14=a2
        负值按 18 位补码放入 WDATA[17:0]，WSTRB = 0xF

步骤 3  回读校验（必须做）
        逐条回读 +0x04..+0x14，与写入值逐位比对；
        读 FSTATUS(0x04)：确认 [15:8] = 0x04 且 [1] coef_dirty = 1
        ★ 任一条不一致 → 停止，不得进入步骤 4

步骤 4  使能影子组
        对 ch0..ch3 写 en = 0x0000_0001

步骤 5  APPLY（一次性把 sh_* → ac_*，同时清内部状态、清 coef_dirty）
        写 FCTRL(0x00) = 0x0000_0003            // bit0=1（WSTRB 必须含 bit0）+ bit1=1
        注意：APPLY 是单拍脉冲，FSTATUS[0] 读不到；
              用 FSTATUS[1] coef_dirty 由 1 变 0 作为"APPLY 已执行"的判据

步骤 6  去旁路（此刻起滤波生效，状态自 0 起，存在启动瞬态）
        写 FCTRL(0x00)        = 0x0000_0000
        写 FBYPASS_MASK(0x08) = 0x0000_0000

步骤 7  回读状态
        FSTATUS[15:8] = 0x04、FSTATUS[1] = 0
        FSAMPLE_HZ(0x0C) = 26000000（用于确认页未错位）

回归    写 FCTRL(0x00) = 0x0000_0001 → 立即回到逐位旁路（V4 逐位回归口径）
```

**顺序禁忌**

- **不要**先关旁路再写系数（存在"使能开、系数旧"窗口）。
- **不要**依赖 `FSTATUS[0]` 判断 APPLY 是否执行（单拍脉冲，AXI 读必然错过）。
- **不要**用 `CLEAR`（`FCTRL[2]`）代替 APPLY（CLEAR 只清状态，不改使能）。
- **不要**在参数化模块里改 RTL 默认值来"改配置"（BD cell 的 CONFIG 才是准）。
- 切换旁路的瞬间，`filt_dv` 会从 `adc_dv[ch]`（直通）切到 `sv[N_STAGE]`（5 拍后），
  **会造成一次采样节拍的错位**。所以**逐位回归只能在旁路态做**。

## 7. 风险与禁止事项

1. **禁止在系数未确认前把旁路默认值改成非旁路**（`fctrl_bypass` / `bypass_mask` 的复位值）。
   保持"上电即逐位旁路"是当前设计的核心安全属性。
2. **禁止为提高"看起来的滤波效果"而放宽饱和**。两级饱和是设计选择，不是缺陷；
   若要改，需同时更新本方案与契约。
3. **门禁 B0 不可跳过**（`generate_target` 后、综合前）：
   ① `<cell>.xml` 含 `dataType="integer"`；② 生成 `.v` 中 `"`+数字 = 0；
   ③ BD 网表 `[0:0]` ≈ 12；④ `.xpr` 中 `$PPRDIR/../` = 0。
   ⚠️ **本树当前 ① ② ③ 通过、④ 不通过（实测 31 处）**：
   21 条指向 `F:/xinya/pd_feature_bd_vivado2020_2/rtl`，2+1 条指向**兄弟树**
   `merge/pd_feature_bd_2020_2/…`（含 `IPStaticSourceDir → …/ipstatic`）。
   **在删除 / 移动 / 修改该兄弟树之前，必须先重新核对本项。**
4. **改动 BD 必须先 `Validate Design`**，不得手工编辑 `.gen` 目录产物。
5. **`a1/a2` 的符号**：RTL 是相减项（`pd_iir_biquad.v:45`），直接填 `a(2)/a(3)`。
   若误加负号，行为是**幅度响应整体变形而非报错**，属静默错误 → 必须靠 V-D 逐位比对兜住。
6. **65 MSPS 直连禁止尝试**：会以"无报错、`dout_dv` 恒 0"的形式静默失效（§3.5）。
7. 本方案的系数**尚未写入接口契约 §8**；写入前"100 kHz–1 MHz"只是内部口径，
   与其他模块（PS 侧 FFT、上位机显示）对齐前不要冻结。
8. **⚠️ 禁止"旁路态标定、滤波态运行"**（§1.6(5)）。滤波把脉冲幅度压到 38.1%，
   而 `cfg_thresh`/`cfg_pos_thr`/`cfg_neg_thr` 全在 **ADC 码域** →
   混用会引入 **2.6 倍的系统性幅度偏差**，且不报任何错。
   **切换滤波状态时必须同步重标**：`cfg_scale`、`cfg_thresh`、`cfg_pos_thr[6]`、`cfg_neg_thr[6]`、`cfg_deadtime`。
9. **⚠️ `cfg_neg_thr` 不得低于 `cfg_pos_thr` 的 13.5%**（§1.6(3)）。
   滤波后的振铃负峰 = 正峰 × 13.5%，若负阈值更低，
   **每一颗超过约 780 码的正极性放电都会在负阈值上再触发一次假事件** →
   帧正/负计数错、PRPD 负半周凭空多一簇。起点建议 `cfg_neg_thr ≥ 0.25 × cfg_pos_thr`。
10. **⚠️ `cfg_deadtime` 必须按振铃宽度重设**（§1.6(4)）。`pd_feature_core.v:768-770`
   明确"跨窗去重不设回差、全靠死区"。滤波把高于门槛的宽度从 4 样点拉到 12 样点，
   跨窗重复计数概率从 0.8% 升到 2.4% → **死区需 ≥ 1 个相位窗（≈508 样点）**。

## 8. 待决策项（需用户 / 与黄贵传确认）

| 编号 | 问题 | 影响 |
|---|---|---|
| D1 | 目标带是否就是 **100 kHz–1 MHz**？是否要写进契约 §8？ | 决定系数是否冻结 |
| D2 | "六组陷波"需求是否仍存在？若指工频及谐波，单节 Q1.16 不可实现（二阶节截止下限约 893 Hz） | 决定 `N_NT` 是否从 0 改回非 0，会改变 `N_STAGE`、系数地址与资源 |
| D3 | B1 选 a/b/c？ | 决定是否新增扫频源 RTL |
| D4 | B2 选 a/b/c/d？ | 决定能否上板定量看波形 |
| D5 | B3 选 a/b/c？ | 决定"溢出状态"是否有寄存器可读 |
| D6 | 65 MSPS 走 CIC 4:1 抽取路径是否确认？（决定第二组系数用 16.25 MHz 还是其它） | 决定 ② 组系数 |
| D7 | **已量化解**：滤波后必须重标定。真实 PD 脉冲被压到约 **38.1%**（DDS 4 样点脉冲）甚至 **17.6%**（单样点脉冲）→ 40 码门槛等效抬高到约 **105 码**（`40/0.381`）。**注意原描述有误**："通带增益 0 dB" 指的是**正弦稳态**响应，不能用来推断脉冲幅度；脉冲经过带通后幅度必然大幅下降（见 §1.6(2)） | 决定 `cfg_scale` / `cfg_thresh` / 两档 `thr` / `cfg_deadtime` 四组参数的取值 |
| D8 | `cfg_neg_thr` 的下限取多少？（建议起点 `≥ 0.25 × cfg_pos_thr`，因振铃负峰 = 正峰 × 13.5%） | 决定是否会产生假负极性事件（§1.6(3)） |
| D9 | 是否需要建立"滤波器在环"的标定流程？（即：标定必须在与运行相同的滤波状态下完成，并把标定值与滤波配置**配套固化**） | 决定交付给用户的标定规程；不解决就会出现"换了滤波配置后数据对不上" |
| D10 | 目标带若最终不是 100 kHz–1 MHz，是否需要保留"旁路存档 + 离线重算"作为唯一权威数据源？（当前 DDR 存原始，**这是对的，不要改**） | 决定是否维持"分析支路用原始数据"的架构 |
