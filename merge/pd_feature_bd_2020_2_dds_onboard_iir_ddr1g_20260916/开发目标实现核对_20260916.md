- 日期：2026-09-16

- 核对原则：仅将当前 RTL、BD 或已记录验证证据支持的功能标为已实现；规划、注释、单次现象均不等同于完成。

## 结论

当前工程已经建立了以 **26 MSPS DDS** 为验证基线的 PL 数据通路：四通道样本打包、公共 CDC、DDR 环形缓存与冻结快照、IIR 滤波链、局放事件/统计 RTL、事件 AXI-DMA 接收测试均已有基础。

但这不等同于《开发目标》的完整交付。特别是 **真实四通道 AD9226 65 MSPS、FFT、独立选频、滤波/频谱/统计结果的 DMA 数据面、PS 网络服务、上位机、端到端与板级验证**仍未完成。

> 说明：四槽自动快照及其 `snapshot_ready` 保持中断属于 DDR 快照功能完善，不是新的主 PL 功能阶段。文档要求的冻结源是 PS 暂停命令；“局放事件自动冻结”可以作为后续增强，但不是本需求文档的硬性条目。

## PL 尚未完成或仅部分完成的功能

### 1. 真实 AD9226 四通道 65 MSPS 采集

未完成。当前为 26 MSPS DDS 测试，尚缺 AD9226 实物接口、65 MSPS 时钟/I/O 约束、四通道同步校验、真实信号质量与板级时序验证。不能把 DDS 跑通表述为“4 路 AD9226 65 MSPS 已完成”。

### 2. FFT 与频谱数据链

未完成。当前工程中没有 FFT IP、FFT RTL 封装、分帧/加窗、复数幅值计算、峰值频点提取或频谱 AXI-Stream 输出。

目标闭环应为：

```text
滤波样本 -> 分帧/加窗 -> FFT IP -> 幅值/峰值 -> AXI-Stream 帧 -> DMA -> PS
```

### 3. 1 kHz 步进的带通高低频配置

仅部分实现。`pd_filter_chain` 可由 AXI-Lite 写入各个 IIR 双二阶节系数，并提供旁路、使能、影子系数和 apply；但尚没有“以 Hz 写入高/低截止频率”的寄存器、1 kHz 步进约束、自动系数生成或已验证的频响指标。因此当前是可配置系数滤波器，而不是已完成的 1 kHz 步进带通功能。

### 4. 独立数字选频功能

未完成。当前的带通/陷波级不能自动等同于目标中的独立选频模块。尚缺中心频率、带宽、选频输出幅值等明确接口与验证。

### 5. 滤波波形、频谱和统计结果 DMA 传输

未完成。当前 AXI DMA 已验证的是 64 bit 局放事件流。目标要求送往 PS 的滤波波形、FFT 频谱、四通道统计结果、max/min 和可能的包络，均还没有对应的 AXI-Stream 帧格式、TLAST 规则、DMA 缓冲策略和解析契约。

### 6. 实时统计结果的完整输出协议

仅部分实现。内部计数和 max/min 已有，但缺少四通道同步统计帧、帧编号、AXI-Stream 封装、DMA 输出和与 PS UDP 帧一致的协议。

### 7. 包络输出

未完成或尚未定义。现有帧内 AD max/min 可作为基础统计，但未见连续包络波形或可 DMA 输出的包络帧。需要先确定包络的数学定义、采样率和传输格式。

### 8. DDR 快照端到端功能验证

尚未完成签收。四槽管理器已有模块级测试，但尚未覆盖“冻结 -> 复制 -> VALID -> 锁定 -> PS 读取 -> 释放 -> 再复用”的完整顶层链路；新增保持中断也尚未验证。真实 65 MSPS 下的 DDR 读写竞争、复制时延和长期稳定性同样没有结论。

## PS 尚未完成的功能

已有 DMA 探针/事件接收程序不等于 PS 业务完成。尚缺：

- 四槽描述符读取、锁定、释放和缓存一致性处理；
- 快照 DDR 区读取与大块数据调度；
- TCP 控制与完整原始波形下载；
- UDP 实时统计、滤波波形和频谱上报；
- UART 调试、命令解析、启停/暂停/恢复/AC-DC/滤波/选频/门限配置；
- 网络断连重连、限速、分帧和异常处理。

## 上位机尚未完成的功能

- 网络与设备配置、采集启停、暂停恢复和状态显示；
- 实时波形、12 档计数、max/min、四通道切换；
- 滤波/选频配置与参数回读；
- FFT 频谱显示；
- TCP 快照下载、四通道同步显示、局部放大与游标测量；
- 椭圆、正弦、直线三种图谱；
- TCP/UDP 协议解析和可视化。

## 验证与签核尚未完成的工作

- 当前 Timing-24 时钟方法学警告处理；
- 当前极小 WNS 裕量的加固；
- IIR 频响、稳定性和定点量化误差验证；
- FFT、选频、统计 DMA 帧的模块与系统仿真；
- 四通道同步、长时间运行、暂停恢复、快照完整性、UDP 高负载和 TCP 大快照传输验证；
- 真实 AD9226 板级验证。

## 推荐的后续 PL 顺序

1. 集成并封装 FFT IP，形成频谱输出通路。
2. 明确“数字选频”是否独立于 IIR；若独立，定义并实现其接口和算法。
3. 统一定义滤波波形、频谱、统计结果的 AXI-Stream 多拍帧格式。
4. 将这些帧接入 DMA，形成完整的 PL 到 PS 实时数据面。
5. 再统一进行模块仿真、顶层仿真、综合、实现、Timing-24 处理和吞吐验证。
6. 之后再进入 PS 的 DDR 槽管理、TCP/UDP 和快照下载业务。
