# 最终定稿：数据流与后续完整实施方案

日期：2026-09-18  
工程：`pd_feature_bd_2020_2_dds_onboard_iir_ddr1g_20260916`  
器件：`xc7z020clg400-2`｜Vivado `2020.2`｜当前原型 `26 MSPS`｜PL `130 MHz`

## 1. 最终架构裁决

```text
ADC/DDS 原始采样
  -> 原始 DDR 环形缓存与四槽快照
  -> PL 实时算法支路
       -> pd_filter_0 前置整形
       -> pd_feature_0 算法核心
            -> 峰值/阈值/事件包
            -> PL 实时 PRPD
            -> event_accept 自动快照触发
  -> PS 快照分析支路
       -> 原始数据解包
       -> FFT/频谱/选频
       -> 离线 PRPD 校核与统计
```

最终规则：

1. `pd_feature_0` 是 PL 实时特征提取和事件判决核心。
2. `pd_filter_0` 是 `pd_feature_0` 的可配置前置预处理模块。
3. PL 保留实时 PRPD，作为产品主路径；PS PRPD 只用于离线校核、显示和算法比较。
4. FFT 属于 `pd_feature` 算法域，但实际执行位置固定在 PS 侧。
5. FFT 输入来自 DDR 原始 ADC 快照，不使用 `filt_data`。
6. 不恢复四路并行 PL FFT，分析支路不得对主采集链施加反压。
7. 当前五拍 IIR 不允许直接接收 65 MSPS。

## 2. 当前实际数据流

```text
pd_dds_0 / 真实 ADC
        | 原始 adc_data/adc_dv
        v
pd_ddr_0：CDC、原始环形写、冻结、四槽快照
        |
        +-- 原始数据 -> DDR 环形区 -> 快照槽 -> PS
        |
        +-- o_feat_data/o_feat_dv -> pd_filter_0
                                      -> pd_feature_0
                                           -> 特征/阈值/PL PRPD
                                           -> event_accept
                                                -> 自动冻结
```

当前 BD 连接：

```text
pd_ddr_0/o_feat_data  -> pd_filter_0/adc_data
pd_ddr_0/o_feat_dv    -> pd_filter_0/adc_dv
pd_filter_0/filt_data -> pd_feature_0/adc_data
pd_filter_0/filt_dv   -> pd_feature_0/adc_dv
pd_feature_0/o_event_accept -> pd_ddr_0/i_event_accept
```

DDR 保存原始采样；滤波只作用于实时判决支路。

## 5. DDR 状态错误门禁

`DDR_STATUS` 定义：

```text
bit[0] acq_en       bit[1] copy_busy       bit[2] hiwm
bit[3] freeze_done  bit[4] snap_overrun    bit[5] err
bit[6] copy_done    bit[7] copy_pending    bit[8] copy_err
bit[9] snapshot_cfg_err
```

因此：

```text
DDR_STATUS=0x00000021
```

表示 `acq_en=1` 且 `err=1`，不能视为无错误通过。软件必须检查：

```text
DDR_STATUS[5]、[8]、[9]
SLOT_STATUS[13]、[14]、[15]
```

在 `err` 来源解释前，不能把该次运行标记为无错误完成。

## 6. 地址、数据和对齐

```text
pd_feature_0 = 0x40000000
pd_ddr_0     = 0x40010000
pd_filter_0  = 0x40020000
axi_dma_0    = 0x40400000
```

一个采样时刻为 48 bit：

```text
[47:36] ch3 [35:24] ch2 [23:12] ch1 [11:0] ch0
```

四个采样时刻组成 24 Byte 原始块。

```text
4 KiB：分区基址、区域边界和 DataMover 区域
24 Byte：单次快照长度和原始块边界
8 Byte：DataMover 地址/访问要求，已被 24 Byte 对齐蕴含
```

单次快照长度不要求 4 KiB 或 `0x3000` 对齐；`3120000 Byte` 合法，因为它是 24 的整数倍。

## 7. 滤波-特征联合标定

解除旁路后必须联合标定：

```text
cfg_thresh、cfg_pos_thr[6]、cfg_neg_thr[6]、cfg_deadtime、
cfg_scale、cfg_reg0_q/cfg_reg1_q
```

流程：

```text
1. 同一激励运行旁路态，记录事件率、正负计数、幅值档和 PL PRPD。
2. APPLY 系数后运行滤波态，记录同一组指标。
3. 联合扫描阈值、正负阈值、死区和比例参数。
4. 检查滤波振铃造成的额外反向事件。
5. 保存最终参数和版本号。
```

禁止用旁路态标定结果直接驱动滤波态。

## 8. DMA/TREADY 门禁

`pd_feature_0/m_axis` 当前连接到：

```text
axi_dma_0/S_AXIS_S2MM
ila_0/SLOT_0_AXIS
```

DMA 未启动时不能假设 `m_axis_tready=1`。正式验证必须：

1. 启动 DMA S2MM 并持续消费事件流；或
2. 增加永久 ready 消费端并重新验证。

在该门禁通过前，只能声明模块仿真和自动快照触发链路通过。

## 9. 65 MSPS 架构

当前 IIR 需要 5 个时钟/样本，130 MHz 下不能直连 65 MSPS。候选架构为：

```text
65 MSPS 原始采集/DDR 存档
 -> 判决支路 CIC 4:1
 -> 16.25 MSPS
 -> IIR
 -> pd_feature 判决核心
```

在 CIC、CDC、时钟、采样率寄存器、相位窗和阈值未重新确认前，不得声称 65 MSPS 产品路径完成。

带宽预算：

```text
4 × 12 bit × 65 MSPS = 390 MB/s
130 MHz × 64 bit = 1040 MB/s
理论占用约 37.5%
```

该数值只是预算，不替代实现和 DDR 争用验证。
