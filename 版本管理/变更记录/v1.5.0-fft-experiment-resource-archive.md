## 为什么要改

为验证四通道滤波数据的 1024 点 FFT、目标频点选择和幅值读取流程，在 Zynq-7020 PL 中集成四个 XFFT IP 与配套 AXI-Stream 适配、监测模块。该实验同时用于获得真实资源占用，并为后续 PS 软件 FFT 建立可比对的参考结果。

## 改了什么

| 文件或模块 | 新增/修改 | 内容摘要 |
|---|---|---|
| `pd_fft_input_adapter_4ch.v` | 新增 | 四路滤波采样转换为 FFT AXI-Stream、1024 点分帧、配置握手与溢出状态。 |
| `pd_fft_bin_monitor_4ch.v` | 新增 | 按每路 `BIN_SEL` 保留单 bin 幅值、帧计数和状态的 AXI4-Lite 监测模块。 |
| `xfft_ch0` ～ `xfft_ch3` | 新增 IP | 四路 1024 点定点 XFFT，Pipelined Streaming I/O。 |
| `pd_feature_bd.bd` 及配套 XCI | 修改 | 加入 FFT 输入、输出、监测与 AXI-Lite 地址映射。 |
| `tb_pd_fft_chain.v` | 新增 | 四路受控正弦输入的 FFT 行为仿真与自动检查。 |
| `tb_pd_fft_chain_wave.tcl` | 新增 | FFT 专用仿真波形集。 |
| `pd_ddr_axil.v`、`pd_ddr_wr_top.v`、`pd_ddr_slot_mgr.v` | 修改 | 自动快照 `snapshot_ready` 状态保持与清除语义完善。 |
| `PL资源不足分析与软硬件划分方案_20260917.md` | 新增 | 资源归因、实时性划分、PS 迁移建议与风险记录。 |

## 不改什么

- 不改变 `pd_feature_0` 的相位、门槛、PRPD 与事件包接口契约。
- 不改变 `pd_ddr_0` 原始环形写、手动 `SNAP_START`、HP0/HP1 映射及既有 AXI4-Lite 地址。
- 不改变 DDR 1 GB 可见范围、时钟频率、CDC 结构和真实 ADC 引脚约束。

## 影响与兼容性

- AXI/寄存器接口：新增 FFT monitor 的 AXI-Lite 从设备及实验寄存器；现有地址不变。
- 时钟、复位、CDC：FFT 使用现有 130 MHz 时钟和 `peripheral_aresetn`；既有数据采集 CDC 不变。
- 仿真激励或预期结果：新增四路 1024 点 FFT 自检 testbench。
- 上板风险：高。四路 Pipelined FFT 导致 PL 放置失败，因此该结构不能用于上板。
