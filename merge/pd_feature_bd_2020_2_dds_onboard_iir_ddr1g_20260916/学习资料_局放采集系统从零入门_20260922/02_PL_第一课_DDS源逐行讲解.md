# 第二章：PL 第一课——`pd_dds_adc_source.v` 逐行讲解

源码：`pd_feature_bd_2020_2.srcs/sources_1/imports/rtl/pd_dds_adc_source.v`  
模块角色：在没有真实 ADC 时，产生四路可综合的 26 MSPS 测试数据。

## 1. 先说结论

当前模块不是“可任意设频的正弦 DDS”。它输出的是：

```text
低幅三角背景波 + 每 20 ms 一次的四路简化局放脉冲 + 50 Hz 同步脉冲
```

它的教学价值是验证完整数字链路：DDS → CDC → 特征/DDR → PS；它不验证真实 ADC 引脚和模拟信号。

## 2. 第 1～12 行：文件说明

| 行号 | 原文/内容 | 解释 |
|---:|---|---|
| 1 | `` `timescale 1ns / 1ps`` | 仿真时间单位为 ns，精度为 ps；综合成硬件时不影响实际时钟。 |
| 2 | 分隔注释 | 只是提高可读性。 |
| 3 | 模块文件名说明 | 告诉读者这是“片内四通道 ADC 测试源”。 |
| 5～6 | 26 MHz 时钟、每拍一个样本 | 这就是 26 MSPS 的定义：每秒 2600 万个采样点。 |
| 7～8 | 背景波与 50 Hz 周期内脉冲 | 解释当前不是纯正弦。 |
| 10～11 | 验证范围 | 明确它会验证数字链路，不会验证真实 ADC 的引脚、电气与时序。 |

## 3. 第 13～25 行：模块参数与端口

```verilog
module pd_dds_adc_source #(
    parameter integer CLK_HZ = 26000000,
    parameter integer SAMPLE_HZ = 26000000,
    parameter integer SYNC_HZ = 50,
    parameter integer ADC_W = 12,
    parameter integer NUM_CH = 4
)( ... );
```

| 行号 | 含义 |
|---:|---|
| 13 | 定义模块，`#(...)` 中是可在实例化时覆盖的参数。 |
| 14 | 输入时钟频率，当前 26 MHz。 |
| 15 | 目标采样率，当前也是 26 MHz。两者相等意味着每个时钟输出一个样本。 |
| 16 | 工频同步频率 50 Hz。 |
| 17 | 每通道 ADC 数据宽度 12 bit。 |
| 18 | 通道数 4。 |
| 20 | `clk`：26 MHz 时钟。 |
| 21 | `rst_n`：低有效复位；`n` 通常表示 negative/low active。 |
| 22 | `adc_data`：总宽度 `4×12=48 bit`；拼接时 ch0 位于最低位。 |
| 23 | `adc_dv`：每通道的 Data Valid。`4'b1111` 表示四路本周期均有效。 |
| 24 | `sync_in`：50 Hz 周期起点标记。 |

## 4. 第 27～33 行：派生常数与寄存器

| 行号 | 解释 |
|---:|---|
| 27 | `CLK_PER_SAMPLE = CLK_HZ / SAMPLE_HZ`。当前等于 1。 |
| 28 | `SYNC_SAMPLES = SAMPLE_HZ / SYNC_HZ = 520000`。一个 50 Hz 周期有 52 万个采样点。 |
| 31 | `tick_div` 是采样分频计数器。当前除数为 1，它每拍都复位。 |
| 32 | `cycle_sample` 记录当前处于 20 ms 周期的第几个采样点。19 bit 足以计到 519999。 |
| 33 | 四个 `phase` 是背景三角波的相位累加器；每路初相不同。 |

## 5. 第 35～42 行：三角波函数

`tri_wave` 的输入是 8-bit 相位，输出约为 `-64` 到 `+63` 的整数三角波。

| 行号 | 解释 |
|---:|---|
| 35 | 定义函数；函数在组合逻辑中计算，不需要单独时钟。 |
| 36 | 输入为 8-bit 相位。 |
| 39 | 相位最高位决定走上坡还是下坡，得到 0～127 的三角形幅值。 |
| 40 | 减 64 把无符号幅值搬到以 0 为中心的有符号波形。 |
| 41～42 | 函数结束。 |

## 6. 第 44～59 行：简化局放脉冲函数

`pd_pulse(sample_pos, centre)` 只在指定位置及之后 3 个点输出非零值。

| 条件 | 输出 |
|---|---:|
| `sample_pos == centre` | 720 |
| `centre + 1` | 600 |
| `centre + 2` | 460 |
| `centre + 3` | 300 |
| 其他位置 | 0 |

这是“衰减脉冲”的最简版本。它能触发特征模块，但没有真实局放常见的高频阻尼振铃；后续会升级为 ROM 波形或阻尼正弦模型。

## 7. 第 61～71 行：12-bit 饱和函数

真实 ADC 的范围是 `0～4095`。`saturate_u12` 防止“背景波 + 脉冲 + DC”超出该范围后回绕成错误数值。

| 行号 | 解释 |
|---:|---|
| 64～65 | 小于 0 时强制为 0。 |
| 66～67 | 大于 4095 时强制为 `12'hFFF`。 |
| 68～69 | 正常范围内取低 12 bit。 |

## 8. 第 73～81 行：定义四路下一拍样本

`sample_ce` 表示“本拍是否产生一个新样本”。当前 `CLK_PER_SAMPLE=1`，因此每个时钟均为真。

| 通道 | DC | 背景波 | 局放脉冲中心 |
|---|---:|---|---:|
| ch0 | 2048 | 三角波右移 2 位，低幅 | 65000 |
| ch1 | 2056 | 三角波右移 2 位，低幅 | 195000 |
| ch2 | 2038 | 三角波右移 1 位，幅值稍大 | 325000 |
| ch3 | 2062 | 三角波右移 2 位，低幅 | 455000 |

这解释了已上板结果 `event=455005/3/2796/748`：ch3 的脉冲设计中心就是 455000，`2796-2048=748` 与 720 脉冲加上 ch3 DC/背景波完全一致。

## 9. 第 83～88 行：仿真/综合前参数保护

| 行号 | 解释 |
|---:|---|
| 83 | `initial` 块在仿真开始时检查参数，也会被综合工具用作常量检查。 |
| 84～85 | 要求“26 MHz 时钟与 26 MSPS”严格整比，否则报错。 |
| 86～87 | 要求 `26,000,000 / 50 = 520,000` 为整数，否则 50 Hz 周期位置会漂移。 |

## 10. 第 90～123 行：真正每拍运行的时序逻辑

| 行号 | 解释 |
|---:|---|
| 90 | 在时钟上升沿更新；`or negedge rst_n` 表示低电平复位可立即生效。 |
| 91～101 | 复位分支：计数器、相位、数据都回到确定初值；`adc_dv=0` 表示复位时没有有效样本。 |
| 102～103 | 每个普通周期先默认把有效信号和同步信号拉低，避免它们意外保持高电平。 |
| 104 | 只有 `sample_ce` 为真才产生新样本。 |
| 105 | 分频器回到 0。 |
| 106 | 用 Verilog 拼接 `{ch3,ch2,ch1,ch0}` 写 48-bit 数据；因此 ch0 在最低 12 bit。 |
| 107 | 四路全部标记有效。 |
| 108 | 仅当本周期第 0 个样本到来时，输出一个时钟宽度的 50 Hz 同步脉冲。 |
| 110～113 | 四路相位按 3、5、7、11 步递增，产生不同的背景频率。 |
| 114～117 | 到第 519999 个样本后回到 0，开始下一个 20 ms 周期。 |
| 118～120 | 若未来把采样率改低，非采样拍只递增分频器，不更新 ADC 数据。 |
| 121～123 | `always` 与模块结束。 |

## 11. 你应亲手完成的小练习

1. 为什么 `520000 / 26000000 = 20 ms`？
2. 为什么 ch3 的局放中心接近你刚才自动定位的 455005？

4. 如果将 `pd_pulse` 的第一个值改为 1200，PS 输出中的 `delta` 大致会怎样变化？
