# 从零学习：局放采集、DDR、PS 分析与网络服务

> 面向对象：没有 FPGA、Verilog、C、Vivado 或 Vitis 基础的学习者。  
> 学习对象：当前已上板验证的 Zynq-7020 工程，而不是抽象示例。  
> 资料建立日期：2026-09-22。

## 先记住一句话

本项目的任务是把四路采样数据可靠地保存到 DDR，再由 ARM（PS）提取事件、快照和频谱结果，并通过网口给 PC 查询或下载。

```text
PL 中的 DDS/未来真实 ADC
        ↓ 四路 12-bit 采样，26 MSPS
PL 特征提取、触发、DDR 环形缓冲和快照复制
        ↓ PS 可访问的 DDR 区域
ARM Cortex-A9：事件归档、快照归档、FFT、TCP 服务
        ↓ TCP 192.168.1.10:6001
PC：命令、下载原始快照、独立复算和后续上位机
```

## 当前真实状态

- 器件：`xc7z020clg400-2`（Zynq-7020）。
- PL 主时钟：约 130 MHz；采样时钟：26 MHz / 26 MSPS。
- 采样格式：四通道、每通道 12-bit offset-binary，名义中值为 2048。
- 每个原始四通道采样点：6 Byte；一份完整快照：3,120,000 Byte，即 520,000 个四通道采样点，约 20 ms。
- PS 频谱：1024 点、去直流、周期 Hann 窗、定点 FFT。
- 已在板上验证：DDR 快照、TCP 下载、快照解包、FFT 自检、自动定位最强偏移点并 FFT。

## 源码位置与学习原则

PL RTL 源码位于：

```text
pd_feature_bd_2020_2.srcs/sources_1/imports/rtl/
```

PS 服务源码位于：

```text
sw/ps_service/
```

每一篇教程都必须同时回答五个问题：

1. 这个模块输入什么、输出什么？
2. 为什么需要它？如果删除会怎样？
3. 它工作在哪个时钟域或处理器环境？
4. 数据在此处如何变化？
5. 如何在仿真、串口或 TCP 输出中证明它正常？

不要一开始背所有代码。先画数据流，再理解一个模块，然后用已经跑通的命令观察它的结果。
