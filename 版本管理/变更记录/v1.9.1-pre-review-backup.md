## 为什么要改

用户要求在继续详细审查和优化 PL、PS、Qt6 上位机之前先备份当前工程。由于本机 Git Credential Manager 没有 GitHub 凭据，用户确认本地备份可接受；因此基线提交 `3ee0aad` 保存在本地分支 `feature/v1.9.1-pre-review-backup`，**尚未推送到 GitHub**。其后同一分支增加了审查修正，详细说明见同目录 `项目审查优化报告_v1.9.1.md`。当前工作树中的后续优化仍未提交，也不代表目标 Vivado 2020.2 已通过验证。

进入 P1 实施前又保存了当前工程状态：本地提交 `893ca49`（同一分支，未推送）。当前静态快照 FFT bins 与 `SCOPE_ENV` Qt 源码推进位于该检查点之后的未提交工作树中。
