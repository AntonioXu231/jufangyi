## 0. 一句话总览

本工程的核心思想只有一句：**一次 ADC 采样，在 `pd_pack48` 之后扇出成三路并行处理**，各走各的时钟、各走各的总线、各存各的 DDR 区域，互不阻塞、互不污染。

- Path A（存档支路）：原始 48bit 样本字 → 异步 FIFO → 192bit 块 → DataMover → PS 的 **HP0** → DDR **环形区**。
- Path B（判决支路）：同一份样本字 → IIR 滤波（默认旁路）→ 特征提取（峰值/PRPD/统计）→ 事件包 AXI-Stream → `ila_0` 与 `axi_dma_0` S2MM → PS DDR。
- Path C（分析支路，纯 PS 软件）：DMA 把事件包搬进 PS DDR 接收缓冲 → 事件归档（16 槽）/快照归档（4 槽）→ 解包 / FFT / TCP 上报。

扇出点位置证据：`pd_ddr_wr_top.v:255-313` 中 `pd_pack48` 同时输出 `o_s48_data`（Path A）与 `o_ch_data`（Path B），随后分别进入两个独立的 48bit 异步 FIFO（`u_fifo48` 与 `u_fifo48_feature`）。这个"两条 48bit 异步 FIFO"就是本工程的**物理扇出边界**。

## 1. "一次采集、单点扇出、三支并行"的架构

### 1.1 扇出点到底在哪

`pd_pack48`（`pd_pack48.v`）在 ADC 时钟域做一件最简单也最关键的事：把一个采样时刻的四通道 12bit 拼成一个 48bit 字，并**同时**给出两份完全相同的副本：

- `o_s48_data` / `o_s48_valid`（`pd_pack48.v:33-34`，连接到 Path A 的 `fifo_48_cdc`）：送 DDR 环形区。
- `o_ch_data` / `o_ch_valid`（`pd_pack48.v:37`，连接到 Path B 的 `fifo_48_feature`）：送实时算法链。

`pd_pack48.v:72-74` 明确写出 `o_s48_data <= s48_word` 与 `o_ch_data <= s48_word` —— **同一份数据、无损复制**。

在 `pd_ddr_wr_top.v:292-313` 中：
- `u_fifo48`（`pd_ddr_wr_top.v:278-290`）是 Path A 的 CDC FIFO，写使能 `fifo_wr_en = s48_a_valid & ~fifo_full & ~fifo_wr_busy`（`:275`）。
- `u_fifo48_feature`（`pd_ddr_wr_top.v:297-309`）是 Path B 的 CDC FIFO，写使能 `feat_fifo_wr_en = s48_b_valid & ~feat_fifo_full & ~feat_fifo_wr_busy`（`:294`）。
- 注释 `pd_ddr_wr_top.v:292-293` 写得很直白："Path B has a separate official asynchronous FIFO. This is the actual fanout boundary: DDR backpressure cannot stall or reorder feature input."

**结论**：扇出发生在 `pd_pack48` 之后的两条 48bit 异步 FIFO 入口；Path A 的反压（DDR 写忙、快照拷贝忙）**永远不可能**影响 Path B 的样本顺序与节拍。

### 1.2 为什么不在单链上"串完"再分叉

如果在单条链上把"带通滤波 → 特征提取 → 打包成 192bit 块 → 写 DDR"全串起来，会有三个致命问题（证据来自契约与各模块注释）：

1. **有损前置风险**：若特征提取或滤波在写 DDR 之前发生，任何一级反压/丢数都会让 DDR 里存的不再是"原始无损样本"。本工程要求 DDR 环形区存"原始码流"（`pd_ddr_defines.vh:11` "100% 利用率无填充"、"原始无损"），所以必须**先把原始样本扇出到 DDR**，过滤/特征只能吃副本。
2. **IIR 非线性相位污染 PRPD 相位**：PRPD（相位分辨局部放电图谱）是按工频相位窗 `phase_win`（`pd_axil_regs.v:17`）统计放电发生时刻的，对**相位零偏**极其敏感。IIR 带通/陷波是**非线性相位**滤波器（`pd_iir_biquad.v` 是二阶 biquad，`PH=5`），会给信号加上与频率相关的群延迟，直接污染 PRPD 的相位坐标。因此 Path B 上的滤波默认**全旁路**（`pd_filter_chain.v:113` `bypass=fctrl_bypass|bypass_mask[ch]`，复位时 `fctrl_bypass<=1; bypass_mask<={NUM_CH{1'b1}}`，`pd_filter_chain.v:86`），只有 Path B 吃滤波副本，绝不污染 Path A 的原始/PRPD 数据。
3. **带通与 FFT 重复两遍**：特征提取需要带通滤波后的波形，而存档需要原始波形；若先滤波再存，存档就拿不到原始波形（丢失物理真值）；若先存原始再在 PS 侧重做滤波/FFT，则 PL 侧重复劳动。扇出后：Path A 存原始、Path B 做判决、Path C（PS）对存档快照再做 FFT（`pd_spectrum.c` 的 1024 点 FFT），职责清晰、互不重复。

## 2. 存档支路（Path A）逐级拆解

数据通路（自顶向下，证据见 `pd_ddr_wr_top.v` 第 2-22 行注释与实例化）：

```
pd_pack48 → fifo_48_cdc(u_fifo48) → pd_pack192 → axis_dfi_64 → dm_wr(DataMover S2MM) → HP0 → DDR 环形区
```

### 2.1 第 1 级：`pd_pack48`（ADC 域，26 MHz）

| 项目 | 值 |
|---|---|
| 输入 | `adc_data[47:0]` = `{ch3,ch2,ch1,ch0}` 偏移二进制（`pd_pack48.v:29`），`adc_dv[4]`（`pd_pack48.v:30`） |
| 输出 | `o_s48_data[47:0]`（48bit 字）、`o_s48_valid`（1bit） |
| 位宽 | 48 bit / 字 |
| 节拍 | 每采样时刻 1 拍（`dv_all` 为真时 `o_s48_valid<=dv_all`，`pd_pack48.v:69`） |
| 背压如何回传 | **不回传**。`pd_pack48` 纯组合+寄存输出，无 ready 反压；ADC 域假设上游持续给数。若 4 路 `dv` 不齐，仅拉 `o_ch_skew_err` 一拍告警、不丢数（`pd_pack48.v:13-15`、`:49`） |

48bit 字内通道排布（契约 §3.1，ch0 在最低位）：`[47:36]ch3 [35:24]ch2 [23:12]ch1 [11:0]ch0`（`pd_ddr_defines.vh:31-36`）。

### 2.2 第 2 级：`fifo_48_cdc`（异步 FIFO，adc_clk→clk 130 MHz）

| 项目 | 值 |
|---|---|
| 实例化 | `u_fifo48`（`pd_ddr_wr_top.v:278`） |
| 写时钟 | `adc_clk`（26 MHz） |
| 读时钟 | `clk`（130 MHz） |
| 深度 | 1024 × 48bit，BRAM，FWFT（`pd_ddr_wr_top.v:271-273`） |
| 写使能 | `s48_a_valid & ~fifo_full & ~fifo_wr_busy`（`:275`） |
| 读使能 | `fifo_rd_en = pk_s48_ready & ~fifo_empty & ~fifo_rd_busy`（`:324`） |
| 背压回传 | FIFO **满**（`fifo_full`）时停止写；`up_ovf`（`:413`）统计"满仍在写"溢出。读侧空时 `rd_en=0`，自然停。 |

这是 Path A 的 CDC 边界，CDC 细节见 B06 第 4、5 节。

### 2.3 第 3 级：`pd_pack192`（clk 130 MHz，48bit→192bit 块）

| 项目 | 值 |
|---|---|
| 输入 | `fifo_dout[47:0]`（来自 FIFO 读侧）、`i_s48_valid=fifo_rd_en`（`:334`） |
| 输出 | `m_axis_tdata[63:0]`、`m_axis_tvalid`/`m_axis_tready`（64bit AXI-Stream） |
| 位宽/节拍 | 4 个 48bit 字 = 1 个 192bit 块 = 3 个 64bit beat（`:48-49`） |
| 整块节拍 | **5 clk/块**（4 字入 + 3 beat 出，`:14-17`，状态机 `pd_pack192.v:100-110`） |
| 背压回传 | `m_axis_tready` 拉低 → 停止发 beat → `wcnt` 饱和在 4 并使 `o_s48_ready=0`（`:19-20`、`:61`），反压逐级传到上游 FIFO，**绝不丢样本** |

关键不变量（`pd_pack192.v:6-12`）：块固定布局 `blk = {W3,W2,W1,W0}`，数值上等于小端整数 `V=W0+W1<<48+W2<<96+W3<<144`；于是 `beat_i = blk[64i +: 64]`，只需 3:1 mux，**无桶形移位器**。

### 2.4 第 4 级：`axis_dfi_64`（AXI-Stream Data FIFO，IP）

| 项目 | 值 |
|---|---|
| 实例化 | `u_dfi`（`pd_ddr_wr_top.v:350`） |
| 深度 | 512 × 64bit = 4096 B > 单次突发 1536 B（`:346-349`），保证 DataMover 命令下发时数据已就位 |
| 作用 | 吸收 Path A 写突发时的流抖动，隔离 DataMover 背压 |
| 背压回传 | `dfi_tready` 由 IP 驱动，回传给 `pd_pack192.m_axis_tready`（`:357`） |

### 2.5 第 5 级：`dm_wr`（AXI DataMover，S2MM）

| 项目 | 值 |
|---|---|
| 实例化 | `u_dm_wr`（`pd_ddr_wr_top.v:364`） |
| 功能 | 把 64bit AXI-Stream 转成 AXI4 突发写，按 `pd_ddr_ring_wr` 下发的命令字（72bit，PG022）搬进 DDR |
| 命令来源 | `pd_ddr_ring_wr`（`u_ring`，`:416`）每攒满 64 块（1536 Byte）发一条突发命令（`pd_ddr_defines.vh:148` `DDR_BURST_BLOCKS=64`） |
| 输出总线 | `m_axi_wr_*` → BD 中 `pd_ddr_0/m_axi_wr` → `axi_smc_hp0` → PS `S_AXI_HP0`（见 B06 第 6 节地址表） |
| 背压回传 | DataMover `m_axi_wr_wready` 由 PS HP 口驱动；写满时 `wlast` 未收完即停发，环形管理器据此控速 |

### 2.6 第 6 级：HP0 → DDR 环形区

- 目的地址：`DDR_RING_BASE = 0x1000_2000`，长度 `DDR_RING_SIZE = 0x07FF_E000`（`pd_ddr_defines.vh:80-81`），即 **128 MiB − 8 KiB**。
- 环形写管理：`pd_ddr_ring_wr`（`:416`）维护写指针 `wr_off`、回绕次数 `wrap_cnt`、已写字节 `wr_bytes`，并在 `cycle_start`（来自 `sync_pulse_0`，BD `sync_pulse_0_cycle_start` 网）处做周期边界标记。
- 突发对齐铁律：`pd_ddr_defines.vh:68-74` 规定起始地址须 8 Byte（AXI 位宽）对齐、块 24 Byte 对齐、且取 LCM(4096,24)=12288=0x3000 的整数倍；校验 `0x1000_2000 / 12288 = 21846` 为整数。

## 3. 判决支路（Path B）逐级拆解

数据通路（依据 BD 网连接 + `pd_feature_sys_top.v` / `pd_feature_top.v`）：

```
pd_ddr_0/o_feat_data → pd_filter_0(IIR, 默认旁路) → pd_feature_0(INPUT_CDC=0)
   → 4×[core+prpd+fifo] → pd_axis_arb → m_axis → ①ila_0  ②axi_dma_0/S_AXIS_S2MM
```

### 3.1 扇出出口：`pd_ddr_0/o_feat_data`

`pd_ddr_wr_top.v:311-313`：`o_feat_data = feat_fifo_dout`（已跨域到 130 MHz 的 48bit 字），`o_feat_dv = {4{feat_fifo_rd_en}}`，`o_feat_ovf` 指示 Path B FIFO 溢出。BD 网 `pd_ddr_0_o_feat_data` 连接到 `pd_filter_0/adc_data`（`pd_feature_bd.bd` 的 `nets`）。

### 3.2 第 1 级：`pd_filter_0`（IIR 带通/陷波链，默认全旁路）

- 实例化：`pd_filter_chain`（`pd_filter_chain.v`）。BD 名 `pd_filter_0`，其 `clk` 由 `clk_wiz_0_clk_out1`（130 MHz）驱动，复位 `rst_n` 来自 `rst_ps7_0/peripheral_aresetn`（`pd_feature_bd.bd` nets）。
- 默认行为：`fctrl_bypass<=1; bypass_mask<={NUM_CH{1'b1}}`（`pd_filter_chain.v:86`），故 `bypass=fctrl_bypass|bypass_mask[ch]` 恒为真，`filt_data = raw`（原样透传，`:114`）。即"默认全旁路"。
- 若使能：每个通道挂若干二阶 biquad（`pd_iir_biquad`，`PH=5`，每样本 5 拍，`pd_iir_biquad.v:9`、`:74`），系数经 AXI-Lite 写 `pd_filter_0/S_AXI`（基址 `0x4002_0000`，见 B06）。
- 背压：无反压（`filt_dv` 跟随 `adc_dv`）。

### 3.3 第 2 级：`pd_feature_0`（特征提取 IP，`INPUT_CDC=0`）

- 实例化：`pd_feature_sys_top`（`pd_feature_sys_top.v`），BD 名 `pd_feature_0`。`INPUT_CDC=0`（`pd_feature_sys_top.v:35`）→ 跳过逐通道 `pd_adc_cdc` FIFO，直接用 `adc_data/adc_dv`（`pd_feature_sys_top.v:155-158` `G_CLK_DOMAIN_INPUT`）。
- 原理：`pd_pack48` 已在 ADC 域完成"四通道一次对齐"，故 Path B 不再对四通道分别做 CDC，避免各通道 FIFO 空标志独立同步造成样本错位（`pd_feature_sys_top.v:121-124` 注释）。
- 输入：`pd_filter_0/filt_data`（BD 网 `pd_filter_0_filt_data` → `pd_feature_0/adc_data`）。`adc_clk` 端口由 `clk_wiz_0_clk_out2`（26 MHz）驱动；`clk` 由 `clk_out1`（130 MHz）驱动（`pd_feature_bd.bd` nets）。

### 3.4 第 3 级：4×[core + prpd + fifo]

`pd_feature_top.v:219-332` 用 `generate` 实例化 4 个通道：
- `pd_feature_core`（`u_core`）：峰值提取、1024 相位窗（`PD_PH_W`）、n/I/P/Q 统计、PRPD 写 RAM。FSM 状态 `S_IDLE/S_PEAK/S_Q1/S_Q2/...`（`pd_feature_core.v:131`），事件链 `S_ACC→S_PEAKN→S_PRRD→S_PRWR` 原子执行（`:538`）。
- `pd_prpd_ram`（`u_prpd`）：每个通道 1024 深 × 16bit PRPD 图谱 RAM（`:296-311`）。
- `pd_axis_fifo`（`u_fifo`）：每通道事件 FIFO，深度 256（`FIFO_AW=8`，`:314-330`）。当事件被本 FIFO 接收时拉 `o_event_accept`（`:377`），该脉冲回灌给 Path A 的自动快照触发（BD 网 `pd_feature_0_o_event_accept` → `pd_ddr_0/i_event_accept`）。

### 3.5 第 4 级：`pd_axis_arb`（beat 级轮询仲裁）

- 实例化：`u_arb`（`pd_feature_top.v:337-352`）。4 通道事件流按 `rr_ptr` 每成功传 1 个 beat 轮转一次（`pd_axis_arb.v:78-83`）。
- 为何 beat 级而非帧级：`pd_axis_arb.v:4-11` 注释——事件稀疏，帧级锁定会阻塞其他通道导致 FIFO 溢出；beat 级保证公平且不丢数。事件包内带 `ch_id[1:0]`，PS 侧按通道重组。

### 3.6 第 5 级：`m_axis` 扇出到 ①`ila_0` ②`axi_dma_0`

BD 接口网 `pd_feature_0_m_axis` 的 `interface_ports` 为：`pd_feature_0/m_axis`、`axi_dma_0/S_AXIS_S2MM`、`ila_0/SLOT_0_AXIS`（`pd_feature_bd.bd` interface_nets）。即事件流**同时**进 ILA（调试观测）和 AXI DMA（搬去 PS）。
- `axi_dma_0/M_AXI_S2MM` → `axi_smc_hp0/S00_AXI` → PS `S_AXI_HP0`（`pd_feature_bd.bd` interface_nets）。注意：事件 DMA 与 Path A 的 `dm_wr` 都走 **HP0**，但分属不同 AXI 主设备，由 SmartConnect 仲裁。

## 4. 分析支路（PS 侧）

依据 `sw/ps_service/include/*.h` 与 `sw/pd_snapshot_poll.c`：

1. **DMA 接收**：`axi_dma_0` S2MM 把 8 字节事件包搬进 PS DDR 接收缓冲 `PD_RX_BUFFER_BASE = PD_PS_DDR_BASE + 0x01000000`，长度 65528 字节（`pd_hw_map.h:78-79`）。
2. **事件归档（16 槽）**：`pd_acq_shared_t.event[16]`（`pd_acquisition.h:39`），结构 `pd_event_record_t`（seq/ddr_addr/bytes/peak/cycle，`pd_acquisition.h:7-13`）。
3. **快照归档（4 槽）**：`pd_acq_shared_t.snapshot[4]`（`pd_acquisition.h:40`），结构 `pd_snapshot_record_t`（sequence/source_slot/source_addr/archive_addr/bytes，`pd_acquisition.h:15-23`）。PS 把 PL 四槽快照（`0x2000_1000..0x2300_1000`）再拷一份到 `PD_SNAP_ARCHIVE_BASE = 0x2400_0000`（`pd_hw_map.h:83`）。
4. **解包**：`pd_snapshot_unpack()`（`pd_snapshot_unpack.c:24`）按 6 字节/样本还原四通道（第 5 节详述）。
5. **FFT**：`pd_spectrum_analyze()` 做 1024 点 FFT（`pd_spectrum.h:8`、`pd_spectrum.c`），结果存 4 记录环 `pd_analysis_record_t[4]`（`pd_analysis.h:8-20`）。
6. **TCP 上报**：`sw/ps_service/tcp/pd_tcp_service.c` 把事件/快照/频谱通过 TCP 发到上位机。

## 5. 存储布局的字节级说明

### 5.1 48bit → 192bit → DDR 字节序

- 一个采样时刻 = 48 bit = 6 Byte，四通道顺序 `[47:36]ch3 [35:24]ch2 [23:12]ch1 [11:0]ch0`（偏移二进制，`pd_ddr_defines.vh:31-36`）。
- 连续 4 个采样时刻 `W0,W1,W2,W3` 拼成 192bit = 24 Byte 块：`blk={W3,W2,W1,W0}`（`pd_pack192.v:6-12`）。
- 块拆成 3 个 64bit beat：`beat0=blk[63:0]`、`beat1=blk[127:64]`、`beat2=blk[191:128]`（`:7`）。
- AXI 写 DDR 时 `tdata` 低字节落低地址，故 beat0 占字节 0..7，beat1 占 8..15，beat2 占 16..23。

### 5.2 数值例子（题目给定）

某时刻四通道原始码：`ch0=0x812`、`ch1=0x7F3`、`ch2=0x900`、`ch3=0x6A1`。

先写 48bit 字（二进制按 12 bit 分组）：
- ch0 = `1000_0001_0010`
- ch1 = `0111_1111_0011`
- ch2 = `1001_0000_0000`
- ch3 = `0110_1010_0001`

PS 侧 `decode_sample()`（`pd_snapshot_unpack.c:6-13`）的内存布局为：
- `p[0] = ch0[7:0]`
- `p[1] = {ch0[11:8], ch1[3:0]}`
- `p[2] = ch1[11:4]`
- `p[3] = ch2[7:0]`
- `p[4] = {ch2[11:8], ch3[3:0]}`
- `p[5] = ch3[11:4]`

逐字节代入：

| 字节 | 表达式 | 数值 |
|---|---|---|
| p[0] | ch0[7:0] = `0001_0010` | **0x12** |
| p[1] | {ch0[11:8]=`1000`, ch1[3:0]=`0011`} = `0011_1000` | **0x38** |
| p[2] | ch1[11:4] = `0111_1111` | **0x7F** |
| p[3] | ch2[7:0] = `0000_0000` | **0x00** |
| p[4] | {ch2[11:8]=`1001`, ch3[3:0]=`0001`} = `0001_1001` | **0x19** |
| p[5] | ch3[11:4] = `0110_1010` | **0x6A** |

**6 个字节 = `0x12, 0x38, 0x7F, 0x00, 0x19, 0x6A`。**

**24 字节块的前 6 字节**：W0 是块内第一个字（`blk[47:0]=W0`，`beat0=blk[63:0]={W1[15:0],W0[47:0]}`），故字节 0..5 正好等于 W0 的 6 字节。即 24 字节块前 6 字节 = **`0x12, 0x38, 0x7F, 0x00, 0x19, 0x6A`**（字节 6..7 才是 W1 的低 16 bit）。

### 5.3 PS 侧如何还原（`decode_sample`）

`pd_snapshot_unpack.c:9-12`：
```
sample[0] = p[0] | ((p[1]&0x0F)<<8)      // = 0x12 | (0x8<<8) = 0x812  ✓ ch0
sample[1] = (p[1]>>4) | (p[2]<<4)        // = 0x3 | (0x7F<<4) = 0x7F3 ✓ ch1
sample[2] = p[3] | ((p[4]&0x0F)<<8)      // = 0x00 | (0x9<<8) = 0x900 ✓ ch2
sample[3] = (p[4]>>4) | (p[5]<<4)        // = 0x1 | (0x6A<<4) = 0x6A1 ✓ ch3
```
四个通道全部还原正确，验证字节序与 `pd_pack48`/`pd_pack192` 的布局契约一致（`pd_snapshot_unpack.h:3-6` 明确"one 48-bit instant = {ch3,ch2,ch1,ch0}; four instants = 24-byte block; little endian"）。

## 6. 容量与速率核算

### 6.1 一条快照为什么是 3,120,000 字节

一个 50 Hz 工频周期 @26 MSPS = 520,000 样本；每样本 6 Byte：
```
520000 × 6 B = 3,120,000 B = 3.12 MB
```
证据：`pd_ddr_defines.vh:78` "50Hz 一个周期 @26MSPS = 5.2e5 样本 × 6B = 3.12 MB"。
- 26 MSPS：3.12 MB/快照
- 65 MSPS：1,300,000 样本 × 6 B = 7.80 MB/快照（`pd_ddr_defines.vh:124`）

### 6.2 环形区能存多少毫秒

环形区容量 `DDR_RING_SIZE = 0x07FF_E000 = 134,184,960 B`（`pd_ddr_defines.vh:81`）。
- 原始码率（26 MSPS）：4ch × 12bit × 26M = **156 MB/s**（`pd_ddr_defines.vh:10`）。
```
134,184,960 B / 156,000,000 B/s ≈ 0.860 s = 860 ms
```
证据：`pd_ddr_defines.vh:79` "环形深度 134.2 MB / 156 MB/s = 860 ms ≈ 43 个工频周期"。
- 若切 65 MSPS：码率 390 MB/s → 134 MB / 390 MB/s ≈ **344 ms ≈ 17 个周期**，仍远大于 1 周期。

### 6.3 四槽为什么各 12 MiB

`DDR_SLOT_SIZE = 0x00C0_0000 = 12,582,912 B = 12 MiB`（`pd_ddr_defines.vh:133`），按"一槽容纳一个完整工频周期"设计：
- 26 MSPS：3.12 MB < 12 MiB（余量 ~3.8×）
- 65 MSPS：7.80 MB < 12 MiB（余量 ~1.5×）
证据：`pd_ddr_defines.vh:122-124`。四槽总跨度 `0x2000_1000..0x2300_1000 = 48 MiB`（`pd_ddr_defines.vh:120`）。

### 6.4 两档速率的容量余量

| 指标 | 26 MSPS | 65 MSPS |
|---|---|---|
| 原始码率 | 156 MB/s | 390 MB/s |
| 环形区可存 | 860 ms（43 周期） | 344 ms（17 周期） |
| 单周期快照 | 3.12 MB | 7.80 MB |
| 单槽(12 MiB)容纳 | ~3.8 周期 | ~1.5 周期 |
| 总线能力（130M×8B） | 1040 MB/s，占用 15% | 占用 37.5% |

结论：两档速率下环形区均 >1 周期、单槽均 >1 周期，余量充足（依据 `pd_ddr_defines.vh:10-13`、`:78-79`、`:122-124`）。

## 7. 节拍与延迟

下面按源码参数/断言累加，给出"一条事件从 ADC 采样到 PS 收到"的环节与各拍数。所有数字均有源码出处；带 `【推测】` 的是无法由单一参数确定的组合延迟。

### 7.1 各环节拍数（来自源码断言/参数）

| 环节 | 域 | 拍数 | 证据 |
|---|---|---|---|
| `pd_adc_cdc` CDC 分频 | 130 MHz | **CDC_RATIO = 5**（26 MHz 档） | `pd_adc_cdc.v:74` `localparam CDC_RATIO = CLK_HZ/SAMPLE_HZ`；注释 `:18-20`（130M/26M→5:1） |
| `pd_adc_cdc` FIFO 同步读额外延迟 | 130 MHz | **+2 拍**（rd_en 后第 2 拍有效，再加 `rd_en_d` 打拍） | `pd_adc_cdc.v:95-109`；`async_fifo.v:18-20` |
| `pd_iir_biquad`（若使能） | 130 MHz | **5 拍/样本** | `pd_iir_biquad.v:9` `PH=5`、`:74` `dout_dv <= (phase==3'd4)` |
| `pd_pack192` | 130 MHz | **5 clk/块**（4 字入+3 beat 出） | `pd_pack192.v:14-17`、`100-110` |
| `pd_feature_core` FSM | 130 MHz | **~4~6 拍/事件**（S_IDLE→S_PEAK→S_Q1→S_Q2→写 PRPD） | `pd_feature_core.v:131` 状态枚举、`:538`、`:649` 起 FSM |
| `pd_axis_arb` 轮转 | 130 MHz | 1 拍/beat | `pd_axis_arb.v:78-83` |
| AXI DMA S2MM + HP0 | 130 MHz↔PS | **【推测】** 数十~数百拍（取决于突发与 PS 内存控制器时延） | 无源码固定值；受 `axi_dma_0` IP 与时序约束决定 |

### 7.2 一条事件的总延迟（从 ADC 采样到 PS 收到）

- **Path A（存档）方向**：ADC(26M) → `pd_pack48`(+1 拍 ADC 域) → `fifo_48_cdc`(CDC, ~5 clk 分频 + 2 拍) → `pd_pack192`(每样本 ~1.25 clk = 5/4) → `axis_dfi_64` → `dm_wr` → HP0 → DDR。Path A 是"持续流"，没有"事件"概念，延迟≈一个块的流水深度（数拍~数十拍）。
- **Path B（判决）方向**：ADC → `pd_pack48`(+1) → `fifo_48_feature`(CDC +2) → `pd_filter_0`(旁路 0 拍 / 使能 5 拍/样本) → `pd_feature_0`(INPUT_CDC=0，直接吃对齐样本) → `pd_feature_core`(~4~6 拍) → `pd_axis_fifo` → `pd_axis_arb`(1 拍/beat) → `m_axis` → `axi_dma_0` S2MM → PS DDR 接收缓冲。
  - 关键额外延迟（Path B 相对 Path A）：`pd_feature_core` 的峰值检测与 PRPD 写、以及 DMA 跨 HP0 到 PS 的内存控制器时延。
  - **【推测】** 合计：在 26 MSPS 档，CDC 5:1 + 核心数拍 + DMA 数十拍，量级约 **数十~数百 ns**（相对 50 Hz 周期 20 ms 可忽略），但对 PRPD 相位窗（1024 窗/周期）而言，"固定流水线延迟"会等效为一个**恒定相位偏移**，必须通过 `pd_feature_core` 的 `u_phase` 相位累加器在契约层面扣除（`pd_feature_core.v:174`、`:182`）。

### 7.3 相位误差估算

- **若 IIR 使能**（非线性相位）：二阶 biquad 的群延迟在带中心约为 `1/(2·fs)` 量级；以 26 MSPS 计，单级 biquad 群延迟 ≈ 1~2 个样本（38.5 ns/样本）。若串 1 级带通，群延迟 `【推测】`约 1~3 样本 → 折算到 1024 窗 PRPD：相位偏移 ≈ (1~3)/1024 窗 ≈ 0.1%~0.3% 窗，虽小但直接污染 PRPD 坐标，故**绝不允许**出现在 PRPD/存档路径上。这正是"默认全旁路"的根本原因（`pd_filter_chain.v:86`、`pd_iir_biquad.v`）。
- **当前默认（旁路）**：`bypass=1` → 滤波零延迟、零相位污染，Path B 的 PRPD 相位与 Path A 的原始样本相位严格同源、零偏。
- 结论：本工程通过"单点扇出 + Path B 旁路 + 相位累加器"三道防线，把 Path B 判决相对 Path A 存档的相位误差控制在**可忽略**量级（默认配置下为 0）。
