## 为什么要改

核心板原理图显示 PS DDR 由两颗 x16、4 Gbit DDR3 颗粒组成 x32 数据总线，物理容量为 1 GB。工程原有 PS DDR 地址窗口与各 HP 主机映射均只有 512 MB，无法用于后续高地址四槽原始波形快照规划。

## 改了什么

| 文件或模块 | 新增/修改 | 内容摘要 |
|---|---|---|
| `merge/pd_feature_bd_2020_2_dds_onboard_iir_ddr1g_20260916/` | 新增 | 从当前 Vivado 工作目录创建的完整本地工程快照。 |
| `.../pd_feature_bd.bd` | 修改 | PS7 DDR 可见范围保存为 `0x0010_0000 - 0x3FFF_FFFF`；HP0/HP1 的 AXI DMA 和 `pd_ddr_0` 主机映射保存为 1 GB。 |
| `.../processing_system7_0_0.xci` | 修改 | 保存 PS7 的 1 GB DDR 地址窗口配置；DDR3 颗粒与物理接口参数保持不变。 |
| `.../scripts/04_restore_v3_axi_address_map.tcl` | 修改 | `m_axi_rd`、`m_axi_wr`、`m_axi_cw` 的恢复范围由 512 MB 改为 1 GB。 |

## 不改什么

- 不改 DDR3 颗粒型号 `MT41K256M16 RE-125`、DDR3 单颗粒位宽 16 Bit、PS DQ=32、DQS=4、DDR PLL 或训练参数。
- 不改 `pd_ddr_0` 的环形缓冲区、单快照区、DMA/Datamover RTL、AXI-Lite 寄存器接口、时钟、复位和 CDC。
- 不实现四槽快照状态机；该功能仅完成设计规划，尚未进入 RTL。
- 不生成 bitstream、不导出新的 XSA、不执行上板测试。

## 影响与兼容性

- AXI/寄存器接口：无变化。`pd_feature_0`、`pd_ddr_0`、`pd_filter_0` 和 `axi_dma_0` 的 AXI-Lite 地址保持不变。
- 时钟、复位、CDC：无变化。
- 仿真激励或预期结果：无变化；本版本未重新运行仿真。
- 上板风险：在重新生成输出产物、综合、实现、生成 bitstream，并且 PS 软件保留 PL 使用的高地址区之前，不得让 PL 访问新增高地址快照区。

## 回退方法

可查看或恢复上一个已验证发布标签：

```powershell
git switch main
git show v1.2.0
```

若需要在 Vivado 中继续使用原有 512 MB 地址窗口，打开 `v1.2.0` 对应工程快照，或将 PS7 `PCW_DDR_RAM_HIGHADDR` 与各 HP 映射恢复为 `0x1FFFFFFF` / 512M 后重新生成输出产物。
