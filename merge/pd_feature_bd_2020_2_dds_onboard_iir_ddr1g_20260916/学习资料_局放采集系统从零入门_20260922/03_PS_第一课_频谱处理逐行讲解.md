# 第三章：PS 第一课——`pd_spectrum.c` 逐行讲解

源码：`sw/ps_service/src/pd_spectrum.c`  
模块角色：从 DDR 快照中读取四路原始采样，去直流、加窗、做 1024 点定点 FFT，并找出各通道最强频率。

## 1. 这份代码为什么运行在 PS

FFT 不是不能放进 PL，而是当前项目优先保证采集和 DDR 通路。把偶发的 1024 点分析放到 ARM，可以节省 PL Slice、DSP 与 BRAM，且便于通过 TCP 输出结果。

## 2. 第 1～10 行：类型与数的表示

| 行号 | 解释 |
|---:|---|
| 1 | 文件目标：给 standalone Cortex-A9 做定点 FFT。 |
| 2 | 引入本模块声明、常量和结果结构体。 |
| 4 | `XST_SUCCESS/XST_FAILURE` 的定义。 |
| 6～9 | `pd_complex_q15_t`：一个复数，有实部 `re`、虚部 `im`，均为 32-bit 有符号数。 |

复数不是“复杂的数据类型”，它只是把一个数表示为：

```text
re + j × im
```

FFT 需要复数来同时表达不同频率分量的幅值和相位。

## 3. 第 11～30 行：正弦查找表

第 12～30 行是一张常量表，只保存正弦波的第一个象限（0 到 90 度）。数值是 Q15 格式：

```text
32767 ≈ 1.0
16384 ≈ 0.5
0     = 0.0
```

只保存四分之一周期，可以用对称关系得到完整 1024 点正弦，节省存储空间。

## 4. 第 32～37 行：Q15 乘法

| 行号 | 解释 |
|---:|---|
| 32 | 定义两个定点数相乘。 |
| 34 | 使用 64-bit 暂存乘积，防止 32-bit 相乘溢出。 |
| 35～36 | 乘积右移 15 位，恢复 Q15 小数点位置；正负数分别四舍五入。 |

例如 Q15 中 `0.5 × 0.5`：`16384 × 16384 >> 15 = 8192`，即 0.25。

## 5. 第 39～56 行：完整正弦与 Hann 窗

| 行号 | 解释 |
|---:|---|
| 39～50 | `sin_turn_1024`：输入 `0～1023` 的相位编号，使用四个象限规则返回完整正弦。 |
| 43 | `& 1023` 让相位自然循环；1024 是 2 的整数次幂，所以可用位运算代替取模。 |
| 44～45 | 高两位确定象限，低八位确定查表位置。 |
| 46～49 | 四个象限的正负与镜像关系。 |
| 52～56 | 计算周期 Hann 窗：窗首尾接近 0，中部接近 1。它降低截断一段非整数周期信号造成的频谱泄漏。 |

## 6. 第 58～95 行：FFT 的主体

FFT 可以理解为把 1024 个时域采样点重新组合成 512 个正频率 bin。

| 行号 | 解释 |
|---:|---|
| 58～68 | `bit_reverse`：把输入样本重排为位反转顺序，这是 radix-2 FFT 的准备步骤。 |
| 62 | 从第 1 个元素开始依次处理。 |
| 63～66 | 计算 bit-reversed 索引，必要时交换两个复数。 |
| 70～74 | `fft_forward` 的变量声明和初始重排。 |
| 75 | FFT 一共经历长度 2、4、8 … 1024 的十级蝶形运算。 |
| 76～82 | 计算当前级的一半长度、旋转因子步长与复数旋转因子。 |
| 83～84 | 计算下半部分数据乘以旋转因子后的复数 `v`。 |
| 85～86 | 读出上半部分数据 `u`。 |
| 87 | 每级右移一位，十级总共除以 1024，防止中间结果溢出。 |
| 88～91 | 蝶形公式：输出 `u+v` 与 `u-v`。 |

## 7. 第 97～112 行：整数开方

频谱幅值为：

```text
sqrt(re² + im²)
```

这里不能依赖浮点 `sqrt()`，因此用纯整数逐位求平方根。第 100 行从最高可能 bit 开始，第 101～110 行逐步逼近结果。

## 8. 第 114～167 行：真正分析一段 DDR 快照

| 行号 | 解释 |
|---:|---|
| 114～115 | 函数入口：`raw` 是快照首地址，`bytes` 是长度，`start_sample` 是 FFT 窗起点。 |
| 117 | 栈上创建 1024 个复数工作区。 |
| 118 | 一次解出的四通道 12-bit 样本。 |
| 124～129 | 检查空指针、采样率、字节对齐与 FFT 窗是否越界；不满足就返回失败。 |
| 127 | `bytes / 6` 得到四通道采样组数。 |
| 131～133 | 在结果中记录本次分析使用的采样率、起点和点数。 |
| 134 | 依次处理 ch0、ch1、ch2、ch3。 |
| 135～142 | 先读 1024 点并求平均值 `dc`，即去直流前的中值。 |
| 144～148 | 再读一次相同的 1024 点，执行 `样本 - dc`，乘 Hann 窗，虚部设为 0。 |
| 149 | 执行前向 FFT。 |
| 150～152 | 从 bin 1 开始搜索，故意跳过 DC bin 0。只搜索到 512，即 Nyquist 频率。 |
| 153～155 | 计算复数功率、开方得到幅值，并乘以 4 补偿内部缩放和窗函数增益。 |
| 156～160 | 保留幅值最大的 bin。 |
| 161～164 | 保存 bin、换算频率和近似幅值。频率公式为 `bin × Fs / 1024`。 |
| 166 | 所有四通道完成，返回成功。 |

## 9. 第 169～204 行：自动选择事件窗口

这就是你实际使用 `FFT AUTO SNAP 0` 的核心。

| 行号 | 解释 |
|---:|---|
| 169～170 | 函数输出一个 `window` 结构体。 |
| 175～179 | 校验快照格式必须是完整的 6 Byte 四通道组，且至少有 1024 点。 |
| 181～183 | 初始化“当前找到的最大偏移点”。 |
| 184 | 遍历整份快照。当前快照为 52 万个采样组。 |
| 185～186 | 调用解包函数，从 6 Byte 还原四路 12-bit 样本。 |
| 187～195 | 对每一路计算 `abs(sample - 2048)`；若更大，保存位置、通道、原始码值。 |
| 198 | 保存最大偏移量。 |
| 199～202 | 让 1024 点窗尽量以事件为中心，即事件前后各约 512 点；靠近快照边界时自动夹紧。 |

因此已上板结果：

```text
event=455005/3/2796/748
start=454493
```

满足 `454493 + 512 = 455005`，正好说明本函数按设计工作。

## 10. 第 206～236 行：为什么 `FFT SELFTEST` 很重要

该自检没有读取真实 DDR，而是在 PS 内部构造四路已知正弦：bin `37/83/151/255`，幅值 1024，DC 2048。

| 行号 | 解释 |
|---:|---|
| 208 | 创建 1024 点、每点 6 Byte 的模拟原始快照。 |
| 209 | 四路预期 bin。 |
| 214～225 | 逐点构造四路正弦，并按项目真实的 6 Byte 格式打包。 |
| 226～228 | 调用真正的 `pd_spectrum_analyze`，而不是另写一套测试算法。 |
| 229～233 | 检查每路 bin 是否精确相等，幅值是否在 900～1150 的允许范围。 |

当 TCP 返回 `FFT_SELFTEST_PASS` 时，能证明 PS 内部的数据解码、Hann 窗、FFT、bin 搜索和幅值缩放都通过了确定性测试。
