# v1.9.0-PS2与Qt6采集栈

## 基本信息

| 项目 | 内容 |
|---|---|
| 版本号 | `v1.9.0` |
| 分支 | `feature/v1.9.0-ps2-host-qt6` |
| 日期 | 2026-09-24 |
| 变更类型 | 功能、文档、仿真模板、上位机 |

## 为什么要改

在 v1.8.0 TCP 原始数据检查点基础上，把 PS 采集/分析服务、Qt 6 主机端和 MATLAB DDS 仿真模板纳入主工程，形成可复现的 PL→PS→TCP→Qt 代码基线，并记录当前工程的真实风险和发布边界。

## 改了什么

| 文件或模块 | 新增/修改 | 内容摘要 |
|---|---|---|
| `sw/ps_service/` | 新增 | 模块化采集、事件/快照解析、FFT、频谱、PRPD、TCP API、批处理/告警/回归脚本 |
| `sw/host_qt6/` | 新增 | Qt 6 Widgets/Network、四通道实时波形、360° 相位图、SCOPE、FFT/PRPD、协议解析 |
| `sim/tb_pd_dds_matlab_template.v` | 新增 | MATLAB 派生 DDS 波形模板仿真激励 |
| `pd_axil_regs.v`、`pd_dds_adc_source.v`、BD/XCI/XPR | 修改 | 当前 DDS、阈值和 BD 配置变更 |
| 《项目全面核查与系统评估报告_20260924.md》 | 新增 | PL/PS/上位机、数据质量、时序和后续验收清单 |
| `.gitignore` | 修改 | 忽略 Qt 本地构建目录和 Qt Creator 用户配置 |

## 不改什么

- 未修改既有 `v1.0.0-baseline`、`v1.5.0` 标签及 `baseline/initial` 分支。
- 未删除或覆盖备份工程、重复 XSA 和另一套 Qt 原型目录；这些目录未纳入本次发布。
- 未宣称当前版本已经完成时序签核、真实 ADC/pC 标定或现场验收。

## 影响与兼容性

- AXI/寄存器接口：沿用当前工程接口；新增内容主要位于 PS TCP 服务和主机端。
- 时钟、复位、CDC：未在本次提交中修复；当前 130 MHz 域时序仍需单独收敛。
- 仿真激励：增加 MATLAB DDS 模板，不改变原有顶层测试平台。
- 上板风险：主工程当前没有可核对的 ELF；必须使用同一版本 manifest 重新生成/下载。
